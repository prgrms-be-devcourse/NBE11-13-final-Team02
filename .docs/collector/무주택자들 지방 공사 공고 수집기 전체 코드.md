# 무주택자들 지방 공사 공고 수집기 전체 코드

Oct 14, 2026 · @beomjunkwon

## 1. 이 문서로 만드는 것

지방 공사 9곳(SH, GH, 부산, iH, 대전, 대구, 울산, 경북, 경남)의 **주거 공고 게시판**에서 새 모집공고를 자동으로 모으는 **collector 워커**(파이썬 3.12)의 전체 코드예요. 준비, DB 테이블, 모든 소스 코드, 테스트, Docker 설정이 실행 순서대로 들어 있어서 위에서부터 따라 만들고 바로 확인할 수 있어요.

collector가 하는 일은 이 다섯 가지예요.

1. 기관 게시판에서 새 글을 찾아요. robots.txt를 지키고 같은 도메인 요청 사이에 4초를 둬요.
2. 제목으로 모집공고·정정공고·후속 안내·제외할 글을 나눠요.
3. 모집공고의 상세 화면과 공고문 원본(PDF·HWP·HWPX) 하나, 주택목록(엑셀 우선)을 받아요.
4. 공고문에서 글자와 표를 뽑고, 표에서 호별 임대조건(전용면적·보증금·월임대료 등)을 읽어요.
5. 원본이 바뀌었을 때만 새 버전으로 저장하고, `raw.notice.collected` 이벤트를 RabbitMQ로 보내요. 자격 조건 해석은 다음 단계(extraction 워커)가 해요.

수집 방식은 **HTTP 요청 + BeautifulSoup**이에요. 9곳 모두 브라우저 없이 목록·상세·첨부를 받을 수 있어요.

**지금 단계**: 이번 주는 로컬(Docker의 PostgreSQL·RabbitMQ·MinIO)에서 개발하고 확인해요. RDS·S3·EC2 연결은 다음 주에 해요. 코드는 환경 변수가 없으면 로컬 값을 쓰도록 만들어서, AWS로 옮길 때 코드는 고치지 않고 환경 변수만 바꿔요.

## 2. 전체 흐름

```
스케줄러 (평일 9~18시 매시 5분 + 매일 새벽 3시 정정 확인, 출처는 하나씩 순서대로)
 │
 └─ 출처마다 (pipeline.run_source)
     ├─ 수집 회차 시작                crawl_runs에 RUNNING
     └─ 게시판마다
         ├─ 목록 1~5페이지            1페이지 해시가 지난번과 같고 밀린 글이 없으면 → 끝
         │   └─ 글마다
         │       ├─ 이미 본 글         목록의 상태·마감일만 갱신
         │       ├─ 365일 넘은 글      SKIPPED로 기록 (열지 않음)
         │       └─ 새 글 분류         NOTICE·CORRECTION → 열기 / FOLLOW_UP → 원래 공고가 있을 때만 / 나머지 → SKIPPED
         ├─ 밀린 글(PENDING·FAILED) + 새 글, 한 번에 최대 20건 (나머지는 PENDING으로 다음 회차)
         │   └─ 글마다
         │       ├─ 상세 화면 읽기     본문, 항목, 첨부 목록
         │       ├─ 공고문 1개         PDF 우선, 못 읽으면 HWP·HWPX → 글자·표 추출
         │       ├─ 주택목록 최대 2개  엑셀 우선 → 호별 임대조건
         │       ├─ S3에 원본 저장
         │       └─ 한 트랜잭션        버전 비교 → 새 버전 저장 + 아웃박스에 raw.notice.collected
         └─ 밀린 글이 없으면 목록 해시 저장
     └─ 회차 마무리                   crawl_runs에 SUCCESS / BLOCKED / FAILED, 새 글 수, 경고

아웃박스 발행기 (5초마다) ──▶ RabbitMQ (mujuthaek.events, 라우팅 키 raw.notice.collected) ──▶ extraction
```

**글 상태 (`raw_posts.status`)**

| 상태 | 뜻 | 다음 회차 |
| --- | --- | --- |
| `SKIPPED` | 열지 않기로 한 글 (모집공고가 아님, 원래 공고가 없는 후속 안내, 365일 넘음) | 다시 보지 않음 |
| `PENDING` | 열어야 하는데 이번 회차 한도(20건)를 넘었거나, 차단으로 멈춘 글 | 목록 위치와 상관없이 먼저 처리 |
| `FAILED` | 상세 화면 구조가 달라 못 읽은 글 | 3번까지 다시 시도 |
| `DONE` | 저장 완료 | 새벽 정정 확인 때 바뀌었으면 새 버전 |

**오류에 따른 반응**

| 오류 | 언제 | 반응 |
| --- | --- | --- |
| `BlockedError` | robots.txt 금지, 403·429, 대기실 화면, robots.txt 서버 오류 | 그 출처의 이번 회차를 멈춤 (`BLOCKED`). 처리 중이던 글은 `PENDING` |
| `ParseError` | 목록 표·본문 영역을 못 찾음 (사이트 구조 변경 신호) | 그 글만 `FAILED`, 경고 기록. 목록이면 그 게시판을 멈춤 |
| `FileRejected` | 첨부가 robots.txt 금지 경로로 넘겨짐, 30MB 초과, 파일 대신 웹페이지 | 그 파일만 건너뛰고 경고 |
| 연결 오류·5xx | 일시적인 오류 | 2번까지 다시 시도, 그래도 안 되면 그 글 `FAILED` |

## 4. DB 테이블

collector 데이터베이스에 테이블 9개를 만들어요. 원본은 고치지 않고 버전으로 쌓고, 목록에서 본 글은 열지 않은 글까지 모두 남겨서 다음 회차에 다시 판단하지 않아요.

| 테이블 | 담는 것 |
| --- | --- |
| `sources` | 수집 출처 9곳 (`code`가 수집기 code와 같아야 함, `enabled`가 false면 정기 수집에서 빠짐) |
| `source_boards` | 게시판별 목록 1페이지 해시, 목록 0건 연속 횟수 |
| `crawl_runs` | 수집 회차 기록 (시작·끝, 상태, 새 글 수, 오류·경고) |
| `raw_posts` | 목록에서 본 모든 글 (상태 `SKIPPED`·`PENDING`·`DONE`·`FAILED`, 원래 공고 연결) |
| `raw_post_versions` | 글의 버전 (본문, 항목, AI에 넘긴 전체 글자, 해시) |
| `raw_files` | 받은 첨부 (기관 주소, 해시, S3 위치, 보관 기한) |
| `raw_texts` | 첨부에서 뽑은 글자 (파일이 지워져도 남음) |
| `raw_units` | 호별 임대조건 (원래 머리글 값과 이상값 기록 포함) |
| `outbox` | 보낼 이벤트 (저장과 같은 트랜잭션) |

`migrations/V202610150900__collector_init.sql`

```sql
-- collector 데이터베이스. 모든 출처의 원본을 고치지 않고 버전으로 쌓아요.

create table sources (
    code       text primary key,          -- 수집기 code (sh, gh, bmc, ih, dcco, dudc, umca, gbdc, gndc)
    name       text not null,
    enabled    boolean not null default true,
    created_at timestamptz not null default now()
);

insert into sources (code, name) values
    ('sh', 'SH 서울주택도시공사'), ('gh', 'GH 경기주택도시공사'), ('bmc', '부산도시공사'),
    ('ih', 'iH 인천도시공사'), ('dcco', '대전도시공사'), ('dudc', '대구도시공사'),
    ('umca', '울산도시공사'), ('gbdc', '경상북도개발공사'), ('gndc', '경상남도개발공사');

-- 게시판별 상태: 목록 1페이지 해시(같으면 그 회차 바로 끝), 목록 0건 연속 횟수(구조 변경 감지)
create table source_boards (
    source_code    text not null references sources (code),
    board_key      text not null,
    last_list_hash text not null default '',
    empty_runs     int  not null default 0,
    last_run_at    timestamptz,
    primary key (source_code, board_key)
);

create table crawl_runs (
    id          uuid primary key,
    source_code text not null references sources (code),
    started_at  timestamptz not null default now(),
    finished_at timestamptz,
    status      text not null default 'RUNNING',  -- RUNNING, SUCCESS, BLOCKED, FAILED
    new_count   int  not null default 0,
    error       text                              -- 오류 또는 경고 모음
);

-- 목록에서 본 모든 글. 열지 않은 글(SKIPPED)도 남겨서 다음 회차에 다시 판단하지 않아요.
create table raw_posts (
    id             uuid primary key,
    source_code    text not null references sources (code),
    board_key      text not null,
    post_key       text not null,                 -- 출처 안에서 유일 (게시판이 여러 개면 접두어)
    kind           text not null,                 -- NOTICE, CORRECTION, FOLLOW_UP, EXCLUDED
    title          text not null,
    posted_on      date,
    detail_url     text,
    list_item      jsonb not null,                -- 목록에서 읽은 값 그대로 (PENDING 글을 다음 회차에 다시 열 때 사용)
    status         text not null,                 -- SKIPPED, PENDING, DONE, FAILED
    attempts       int  not null default 0,       -- FAILED 재시도 횟수 (3번까지)
    last_error     text,
    list_status    text,                          -- 목록의 상태 (접수중, 모집종료 …)
    deadline_on    date,
    parent_post_id uuid references raw_posts (id), -- 정정공고·후속 안내가 가리키는 원래 모집공고
    latest_version int  not null default 0,
    created_at     timestamptz not null default now(),
    updated_at     timestamptz not null default now(),
    unique (source_code, post_key)
);
create index raw_posts_queue_idx on raw_posts (source_code, board_key, status) where status in ('PENDING', 'FAILED');

create table raw_post_versions (
    id           uuid primary key,
    raw_post_id  uuid not null references raw_posts (id),
    version      int  not null,
    content_hash text not null,                   -- 본문 + 첨부 해시. 같으면 새 버전을 만들지 않음
    body_text    text not null,
```

### 5-3. robots.txt 해석 — `core/robots.py`

파이썬 기본 해석기는 `/*.xls$` 같은 `*`·`$` 패턴을 무시해서 막힌 주소를 허용으로 잘못 판단해요. 그래서 표준(RFC 9309)대로 직접 해석해요.

```python
"""robots.txt 해석 (RFC 9309).

파이썬 기본 해석기(urllib.robotparser)는 '/*.xls$' 같은 * · $ 패턴을 이해하지 못해서 직접 구현해요.
- 우리 수집기 이름과 맞는 그룹이 있으면 그 그룹, 없으면 '*' 그룹
- 주소의 경로+쿼리에 맞는 규칙 중 가장 긴 것을 따르고, 길이가 같으면 Allow
- 맞는 규칙이 없으면 허용
"""

import re
import urllib.parse


class RobotRules:
    def __init__(self, text: str, agent: str):
        groups: list[dict] = []
        current: dict | None = None
        rules_started = False
        for raw in text.splitlines():
            line = raw.split("#", 1)[0].strip()
            if ":" not in line:
                continue
            field, value = (part.strip() for part in line.split(":", 1))
            field = field.lower()
            if field == "user-agent":
                if current is None or rules_started:
                    current, rules_started = {"agents": [], "rules": []}, False
                    groups.append(current)
                current["agents"].append(value.lower())
            elif field in ("allow", "disallow") and current is not None:
                rules_started = True
                if value:  # 빈 Disallow는 '전부 허용'이라 규칙으로 넣지 않음
                    current["rules"].append((field == "allow", value))
        token = agent.lower().split("/")[0]
        mine = [g for g in groups if any(a != "*" and a in token for a in g["agents"])]
        chosen = mine or [g for g in groups if "*" in g["agents"]]
        self.rules: list[tuple[bool, str]] = [rule for group in chosen for rule in group["rules"]]

    @staticmethod
    def _matches(pattern: str, path: str) -> bool:
        regex = re.escape(pattern).replace(r"\*", ".*")
        if regex.endswith(r"\$"):
            regex = regex[:-2] + "$"
        return re.match(regex, path) is not None

    def can_fetch(self, url: str) -> bool:
        parts = urllib.parse.urlsplit(url)
        path = (parts.path or "/") + (f"?{parts.query}" if parts.query else "")
        hits = [(len(pattern), allow) for allow, pattern in self.rules if self._matches(pattern, path)]
        if not hits:
            return True
        longest = max(length for length, _ in hits)
        return any(allow for length, allow in hits if length == longest)


ALLOW_ALL = RobotRules("", "any")
```

### 5-4. 예의 있는 HTTP 클라이언트 — `core/http_client.py`

모든 요청이 여기를 지나요. 주소 이동(302)을 직접 따라가면서 이동한 주소마다 robots.txt를 다시 확인해요. SH처럼 허용된 다운로드 주소가 금지 경로(`/upload`)로 넘기는 경우를 막기 위해서예요. `transport`·`sleep`을 바꿔 넣을 수 있어서 테스트에서는 실제 사이트에 요청하지 않아요.

```python
"""기관 사이트에 예의 있게 요청하는 클라이언트.

- 모든 요청(이동한 주소 포함) 직전에 robots.txt 확인. robots.txt는 도메인마다 24시간 캐시
- 같은 도메인은 정해진 간격(기본 4초)을 두고 요청
- 연결 오류·5xx는 2번까지 다시 시도, 403·429와 대기실 화면은 BlockedError로 그 출처 회차 중단
- 파일 다운로드는 크기 상한, 파일 대신 웹페이지가 오면 거부
"""

import json
import ssl
import time
import urllib.parse
from typing import Any

import httpx

from mujuthaek_collector.config import USER_AGENT
from mujuthaek_collector.core.robots import ALLOW_ALL, RobotRules
from mujuthaek_collector.errors import BlockedError, FileRejected

ROBOTS_TTL_SECONDS = 24 * 60 * 60
MAX_REDIRECTS = 5


def decode(response: httpx.Response) -> str:
    """응답 문자 인코딩: 헤더에 있으면 그대로, 없으면 UTF-8 → CP949(EUC-KR) 순서로."""
    if response.charset_encoding:
        return response.text
    try:
        return response.content.decode("utf-8")
    except UnicodeDecodeError:
        return response.content.decode("cp949", errors="replace")


def looks_like_waiting_room(html: str) -> bool:
    """대기실(NetFunnel 등) 화면인지. SH는 정상 페이지에도 NetFunnel 스크립트가 들어 있어서,
    스크립트가 있어도 표나 충분한 본문이 있으면 정상 페이지로 봐요."""
    lower = html.lower()
    if "netfunnel" not in lower:
        return False
    if "<tbody" in lower or "<table" in lower:
        return False
    visible = len("".join(part for part in lower.split("<") if ">" in part))
    return visible < 1500


class PoliteClient:
    def __init__(
        self,
        *,
        delay_seconds: float = 4.0,
        legacy_tls: bool = False,
        timeout: float = 20.0,
        max_file_bytes: int = 30 * 1024 * 1024,
        user_agent: str = USER_AGENT,
        transport: httpx.BaseTransport | None = None,
        sleep=time.sleep,
    ):
        verify: ssl.SSLContext | bool = True
        if legacy_tls:  # 예전 보안 연결만 받는 기관용. 인증서 확인은 유지하고 예전 암호 방식만 추가로 허용
            context = ssl.create_default_context()
            context.set_ciphers("DEFAULT:@SECLEVEL=1")
            context.options |= getattr(ssl, "OP_LEGACY_SERVER_CONNECT", 0x4)
            verify = context
        self._client = httpx.Client(
            headers={"User-Agent": user_agent},
            timeout=timeout,
            verify=verify,
            follow_redirects=False,  # 이동하는 주소마다 robots.txt를 확인하려고 직접 따라감
            transport=transport,
        )
        self._user_agent = user_agent
        self._delay = delay_seconds
        self._max_file_bytes = max_file_bytes
        self._last_request: dict[str, float] = {}
        self._robots: dict[str, tuple[float, RobotRules]] = {}
        self._sleep = sleep

    def close(self) -> None:
        self._client.close()

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.close()

    # ── 공개 메서드 ──────────────────────────────────────────────────────
    def allowed(self, url: str) -> bool:
        return self._rules_for(url).can_fetch(url)

    def text(self, url: str, *, data: dict[str, str] | None = None, referer: str | None = None) -> str:
        """페이지를 글자로 받아요. data가 있으면 폼 POST로 보내요."""
        response = self._send("POST" if data is not None else "GET", url, data=data, referer=referer)
        body = decode(response)
        if looks_like_waiting_room(body):
            raise BlockedError(f"대기실 화면이 와서 이번 회차를 멈춰요: {url}")
        return body

    def json(self, url: str, *, referer: str | None = None) -> Any:
        body = self.text(url, referer=referer)
        try:
            return json.loads(body)
        except ValueError as error:
            raise BlockedError(f"JSON 대신 다른 응답이 왔어요 (구조 변경 또는 차단): {url}") from error

    def download(self, url: str, *, referer: str | None = None) -> bytes:
        """공고문 원본 파일. robots 허용 경로만, 크기 상한, 웹페이지가 오면 거부."""
        try:
            response = self._send("GET", url, referer=referer, stream=True)
        except BlockedError as error:
            if "robots.txt" in str(error):
                raise FileRejected(str(error)) from error
            raise
        try:
            if "text/html" in (response.headers.get("Content-Type") or "").lower():
                raise FileRejected("파일 대신 웹페이지가 왔어요 (주소나 권한 확인 필요)")
            if int(response.headers.get("Content-Length") or 0) > self._max_file_bytes:
                raise FileRejected(f"파일이 {self._max_file_bytes // 1024 // 1024}MB보다 커서 받지 않아요")
            chunks, size = [], 0
            for chunk in response.iter_bytes():
                size += len(chunk)
                if size > self._max_file_bytes:
                    raise FileRejected(f"파일이 {self._max_file_bytes // 1024 // 1024}MB보다 커서 받지 않아요")
                chunks.append(chunk)
            return b"".join(chunks)
        finally:
            response.close()

    # ── 내부 ──────────────────────────────────────────────────────────
    def _rules_for(self, url: str) -> RobotRules:
        parts = urllib.parse.urlsplit(url)
        host = parts.netloc
        cached = self._robots.get(host)
        if cached and time.time() - cached[0] < ROBOTS_TTL_SECONDS:
            return cached[1]
        self._wait(host)
        robots_url = f"{parts.scheme or 'https'}://{host}/robots.txt"
        try:
            response = self._client.get(robots_url, follow_redirects=True)
        except httpx.HTTPError as error:
            raise BlockedError(f"robots.txt를 받지 못해 이 도메인은 요청하지 않아요: {host} ({error})") from error
        finally:
            self._last_request[host] = time.time()
        if 400 <= response.status_code < 500:
            rules = ALLOW_ALL  # robots.txt가 없으면(4xx) 표준상 전체 허용
        elif response.status_code >= 500:
            raise BlockedError(f"robots.txt 서버 오류({response.status_code})라 이 도메인은 요청하지 않아요: {host}")
        else:
            rules = RobotRules(decode(response), self._user_agent)
        self._robots[host] = (time.time(), rules)
        return rules

    def _wait(self, host: str) -> None:
        elapsed = time.time() - self._last_request.get(host, 0.0)
        if elapsed < self._delay:
            self._sleep(self._delay - elapsed)

    def _send(self, method: str, url: str, *, data=None, referer=None, stream=False, retries=2) -> httpx.Response:
        for _ in range(MAX_REDIRECTS + 1):
            if not self.allowed(url):
                raise BlockedError(f"robots.txt가 막은 주소라 요청하지 않아요: {url}")
            response = self._send_once(method, url, data=data, referer=referer, stream=stream, retries=retries)
            if response.is_redirect:
                location = urllib.parse.urljoin(url, response.headers.get("Location", ""))
                response.close()
                if response.status_code in (301, 302, 303):
                    method, data = "GET", None
                referer, url = url, location
                continue
            return response
        raise BlockedError(f"주소 이동이 너무 많아요: {url}")

    def _send_once(self, method, url, *, data, referer, stream, retries) -> httpx.Response:
        host = urllib.parse.urlsplit(url).netloc
        headers = {"Referer": referer} if referer else {}
        last_error: Exception | None = None
        for attempt in range(retries + 1):
            self._wait(host)
            try:
                request = self._client.build_request(method, url, data=data, headers=headers)
                response = self._client.send(request, stream=stream)
            except httpx.TransportError as error:
                last_error = error
                self._last_request[host] = time.time()
                self._sleep(self._delay * (2**attempt))
                continue
            self._last_request[host] = time.time()
            if response.status_code in (403, 429):
                response.close()
                raise BlockedError(f"HTTP {response.status_code} 응답이라 이번 회차를 멈춰요: {url}")
            if response.status_code >= 500 and attempt < retries:
                response.close()
                self._sleep(self._delay * (2**attempt))
                continue
            if response.status_code >= 400:
                response.close()
                raise httpx.HTTPStatusError(f"HTTP {response.status_code}: {url}", request=request, response=response)
            return response
        raise httpx.ConnectError(f"연결 실패: {url} ({last_error})")
```

### 5-5. HTML 읽기 도우미 — `core/html.py`

기관별 파서는 이 함수들로만 HTML을 읽어요. `body_text`는 본문 안의 표를 `칸 | 칸` 줄로 바꿔 AI 추출 단계가 표를 읽을 수 있게 하고, 한글 문서에서 붙여 넣은 본문처럼 글자마다 `<span>`이 끊긴 경우에도 단어가 쪼개지지 않게 이어 붙여요. `table_grid`는 합쳐진 칸을 펼쳐서 PDF 표와 같은 모양으로 만들어요.

```python
"""HTML 읽기 도우미 (BeautifulSoup + lxml). 기관별 파서는 이 함수들만 써서 HTML을 읽어요."""

import copy
import re
import urllib.parse
from datetime import date
from html import unescape

from bs4 import BeautifulSoup, Comment, Tag

BLOCK_TAGS = ["p", "div", "li", "tr", "h1", "h2", "h3", "h4", "h5", "h6", "dd", "dt"]


def soup(markup: str) -> BeautifulSoup:
    return BeautifulSoup(markup, "lxml")


def text_of(node: Tag | None) -> str:
    """태그 안의 글자를 한 줄로 (공백 정리)."""
    if node is None:
        return ""
    return re.sub(r"\s+", " ", node.get_text(" ")).replace("\xa0", " ").strip()


def abs_url(base: str, href: str) -> str:
    return urllib.parse.urljoin(base, unescape(href.strip()))


def query_of(url: str) -> dict[str, str]:
    return dict(urllib.parse.parse_qsl(urllib.parse.urlsplit(unescape(url)).query))


def js_args(script: str, func: str) -> list[str] | None:
    """onclick="setView('123')" 같은 스크립트 호출에서 인자를 꺼내요."""
    found = re.search(re.escape(func) + r"\s*\(([^)]*)\)", script or "")
    if not found:
        return None
    return [a.strip().strip("'\"") for a in found.group(1).split(",")]


def table_grid(table: Tag) -> list[list[str]]:
    """표를 격자로. 합쳐진 칸(colspan·rowspan)은 펼쳐서 첫 칸에만 값을 두고 나머지는 빈 칸으로 둬요.
    PDF 표(pdfplumber)와 같은 모양이 돼서 두 줄 머리글·세로 병합 처리를 같은 함수로 할 수 있어요."""
    grid: list[list[str]] = []
    pending: dict[tuple[int, int], str] = {}
    rows = [tr for tr in table.find_all("tr") if tr.find_parent("table") is table]
    for r, tr in enumerate(rows):
        cells: list[str] = []
        c = 0
        for cell in tr.find_all(["td", "th"], recursive=False):
            while (r, c) in pending:
                cells.append(pending.pop((r, c)))
                c += 1
            colspan = int(cell.get("colspan", 1) or 1)
            rowspan = int(cell.get("rowspan", 1) or 1)
            value = text_of(cell)
            for k in range(colspan):
                cells.append(value if k == 0 else "")
                for down in range(1, rowspan):
                    pending[(r + down, c + k)] = ""
            c += colspan
        while (r, c) in pending:
            cells.append(pending.pop((r, c)))
            c += 1
        grid.append(cells)
    width = max((len(row) for row in grid), default=0)
    return [row + [""] * (width - len(row)) for row in grid]


def body_text(node: Tag | None) -> str:
    """본문 HTML을 글자로. 표는 안쪽 표부터 '칸 | 칸' 줄로 바꿔 행·열 관계를 살려요.
    한글 문서에서 붙여 넣은 본문은 몇 글자마다 <span>이 끊겨 있어서, 줄 단위 태그만 줄바꿈하고
    나머지 태그는 공백 없이 이어 붙여요."""
    if node is None:
        return ""
    node = copy.copy(node)
    for comment in node.find_all(string=lambda s: isinstance(s, Comment)):
        comment.extract()  # 주석 처리된 예전 문구는 빼기
    for tag in node.find_all(["script", "style"]):
        tag.decompose()
    while True:
        leaf = next((t for t in node.find_all("table") if t.find("table") is None), None)
        if leaf is None:
            break
        rows = [" | ".join(row) for row in table_grid(leaf) if any(row)]
        leaf.replace_with("\n[표]\n" + "\n".join(rows) + "\n")
    for br in node.find_all("br"):
        br.replace_with("\n")
    for tag in node.find_all(BLOCK_TAGS):
        tag.append("\n")
    text = node.get_text("").replace("\xa0", " ")
    return "\n".join(re.sub(r"[ \t]+", " ", line).strip() for line in text.splitlines() if line.strip())


DATE_PATTERNS = [
    re.compile(r"(?P<y>\d{4})\s*[.\-/년]\s*(?P<m>\d{1,2})\s*[.\-/월]\s*(?P<d>\d{1,2})"),
    re.compile(r"(?<!\d)(?P<y>\d{2})\s*\.\s*(?P<m>\d{1,2})\s*\.\s*(?P<d>\d{1,2})"),
]


def parse_date(text: str | None) -> date | None:
    """기관마다 다른 날짜 모양(2026-10-08, 2026.10.08, 2026년 10월 8일, 26. 10. 8.)을 date로."""
    for pattern in DATE_PATTERNS:
        found = pattern.search(text or "")
        if found:
            year = int(found.group("y"))
            year = year + 2000 if year < 100 else year
            try:
                return date(year, int(found.group("m")), int(found.group("d")))
            except ValueError:
                return None
    return None
```

### 5-6. 제목 분류 — `core/classify.py`

지방 공사 게시판에는 모집공고 말고도 후속 안내(당첨자 발표 등), 정정공고, 기존 입주자 안내(재계약), 공사가 집을 사는 매입 공고, 토지·용지 공급, 상가 입점자 모집이 섞여 있어요. 제목만으로 나누고, 후속 안내는 제목 속 "(공고명, 공고일)"로 원래 모집공고를 찾아요.

| 제목 예 | 결과 |
| --- | --- |
| 2026년 하반기 신혼·신생아 매입임대주택Ⅱ 입주자 모집공고 | `NOTICE` |
| 2026년 행복주택 입주자 모집공고 \[정정공고\] | `CORRECTION` |
| 성북구 연극인주택 잔여세대 입주자 모집공고(26. 7. 8.) 당첨자발표 및 계약안내 | `FOLLOW_UP` |
| 2026년 기존주택 매입 공고, ○○지구 공동주택용지 공급 공고 | `EXCLUDED` |
| 임대아파트 단지 내 상가 입점자 모집 공고 | `EXCLUDED` (사업공간은 이 수집기 범위 밖) |
| 임대주택 재계약 안내 | `EXCLUDED` |

```python
"""제목으로 글 종류를 나눠요. 기관 게시판에는 모집공고 말고도 후속 안내·정정공고·기존 입주자 안내·매입 공고가 섞여 있어요.

결과
  NOTICE      모집공고 → 상세를 연다
  CORRECTION  정정공고 → 상세를 열고 원래 공고에 연결
  FOLLOW_UP   후속 안내(당첨자 발표, 서류제출 대상자 등) → 원래 모집공고가 있을 때만 열고 연결
  EXCLUDED    그 밖의 글 → 열지 않음
"""

import re
from dataclasses import dataclass
from datetime import date

NOTICE, CORRECTION, FOLLOW_UP, EXCLUDED = "NOTICE", "CORRECTION", "FOLLOW_UP", "EXCLUDED"
OPEN_KINDS = {NOTICE, CORRECTION}

FOLLOWUP = re.compile(
    r"당첨자|계약\s*대상자|계약\s*안내|서류\s*심사|심사\s*대상자|대상자\s*발표|입주\s*대상자|예비자\s*발표|면접|교육\s*이수"
    r"|접수\s*결과|접수\s*마감|주택\s*공개|커트라인|추첨\s*결과|동\s*·?\s*호\s*추첨|결과\s*발표|모집\s*결과|선정\s*결과"
    r"|계약\s*체결|서류\s*제출\s*대상|대상자\s*안내|신규\s*계약|접수\s*번호|입주\s*순번|순번\s*(?:추첨|결정)"
)
EXISTING = re.compile(r"재계약|갱신\s*계약")  # 기존 입주자 안내
# 입주자 모집이 아닌 공고: 공사가 집을 사는 매입 공고, 사업자 공모, 토지·용지 공급, 보상, 평가위원
NOT_TENANT = re.compile(
    r"(?:기존\s*)?주택\s*매입\s*(?:재)?공고|매입\s*(?:재)?공고|사업자\s*(?:공모|모집)|택지|용지|수의\s*계약|낙찰"
    r"|보상\s*(?:계획|공고)|평가\s*위원|위원\s*(?:후보|모집|명단)"
)
BUSINESS_SPACE = re.compile(r"상가|점포|입점|사무실|창업|업무시설|근린생활|임차인")  # 이 수집기 범위 밖 (사업공간)
CORRECTION_MARK = re.compile(r"[\[(]\s*정정\s*(?:공고)?\s*[\])]|정정\s*공고")
RECRUIT = re.compile(r"모집\s*공고|입주자\s*모집|예비\s*입주자|추가\s*모집|잔여\s*세대.*모집")
REF = re.compile(r"(?P<name>.+?)\s*\(\s*(?:공고일?\s*:?\s*)?[‘'’]?(?P<y>\d{2,4})\s*[._]\s*(?P<m>\d{1,2})\s*[._]\s*(?P<d>\d{1,2})\s*\.?\s*(?:공고)?\s*\)")


def classify(title: str) -> str:
    if EXISTING.search(title) or NOT_TENANT.search(title) or BUSINESS_SPACE.search(title):
        return EXCLUDED
    ref = REF.search(title)
    if ref and re.search(r"모집\s*공고", ref.group("name")) and len(re.sub(r"[^가-힣]", "", title[ref.end() :])) >= 2:
        return FOLLOW_UP  # '…모집공고(2026. 6. 25.) 면접평가 대상자 발표'처럼 공고일 뒤에 글이 붙으면 후속 안내
    if FOLLOWUP.search(title):
        return FOLLOW_UP
    if CORRECTION_MARK.search(title) and RECRUIT.search(title):
        return CORRECTION
    if RECRUIT.search(title):
        return NOTICE
    return EXCLUDED


def norm_name(text: str) -> str:
    """공고 이름 비교용: 꾸밈말([당첨자발표], (수요자맞춤형))과 '모집공고' 같은 공통 단어를 빼요."""
    text = re.sub(r"\[[^\]]*\]|\([^)]*\)", " ", text)
    text = re.sub(r"입주자|모집\s*공고문?|모집|공고|잔여\s*세대|예비|정정", " ", text)
    return re.sub(r"[^0-9A-Za-z가-힣]", "", text)


@dataclass(frozen=True)
class TitleRef:
    name: str
    posted_on: date


def title_ref(title: str) -> TitleRef | None:
    """후속 안내 제목 안의 '(2026. 8. 21.)' 같은 공고일과 그 앞의 공고명. 원래 모집공고를 찾는 데 써요."""
    found = REF.search(title)
    if not found:
        return None
    year = int(found.group("y"))
    year = year + 2000 if year < 100 else year
    try:
        return TitleRef(norm_name(found.group("name")), date(year, int(found.group("m")), int(found.group("d"))))
    except ValueError:
        return None


def same_notice(ref: TitleRef, title: str, posted_on: date | None) -> bool:
    """후속 안내가 가리키는 (공고명, 공고일)과 모집공고가 같은지."""
    own = norm_name(title)
    same_name = bool(ref.name and own) and (ref.name in own or own in ref.name)
    return same_name and posted_on == ref.posted_on


def correction_base(title: str) -> str:
    """정정공고를 원래 공고와 비교할 이름 (정정 표시를 뺀 공고명)."""
    return norm_name(CORRECTION_MARK.sub("", title))
```

### 5-7. 첨부 고르기 — `core/files.py`

첨부는 이름으로 역할을 나눠요. 공고문은 **하나만** 받고(첫 번째가 실패하면 두 번째), 주택목록은 같은 목록이 엑셀·PDF로 있으면 엑셀 하나만 받아요. 명단·신청서·도면은 받지 않아요.

```python
"""첨부 고르기. 공고문은 하나만, 주택목록은 엑셀 우선으로 최대 2개, 명단·신청서·도면은 받지 않아요."""

import re
from dataclasses import dataclass

PERSONAL_FILE = re.compile(r"명부|명단|당첨자|예비자|계약\s*대상자|합격자")  # 사람 이름이 담긴 파일: 받지도 열지도 않음
NOTICE_FILE_NAME = re.compile(r"공고문|모집\s*공고")
NOT_NOTICE_FILE = re.compile(r"안내문|커트라인|결과|양식|서약서|위임장|동의서|신청서|위치도|평면도|배치도|도면")
UNIT_LIST_FILE = re.compile(
    r"주택\s*목록|공급\s*(?:주택\s*)?목록|임대\s*조건|호별|대상\s*주택|주택\s*현황|단지\s*목록|모집\s*호수|공급\s*현황|주택\s*리스트"
    r"|공급\s*가능\s*주택|건물\s*목록"
)
FILE_EXT = re.compile(r"\.(hwpx?|pdf|zip|docx?|xlsx?|xlsm|jpe?g|png)\s*$", re.I)
DOC_EXTS = ("pdf", "hwp", "hwpx")
TABLE_EXTS = ("xlsx", "xlsm", "pdf", "hwpx", "hwp")


@dataclass
class FileRef:
    name: str
    url: str
    index: int
    size: int | None = None

    @property
    def ext(self) -> str:
        found = FILE_EXT.search(self.name)
        return found.group(1).lower() if found else ""

    @property
    def personal(self) -> bool:
        return bool(PERSONAL_FILE.search(self.name))

    @property
    def unit_list(self) -> bool:
        return bool(UNIT_LIST_FILE.search(self.name)) and not self.personal

    @property
    def notice_doc(self) -> bool:
        return not self.personal and not self.unit_list and not NOT_NOTICE_FILE.search(self.name)


def pick_notice_files(files: list[FileRef], prefer: str = "pdf") -> list[FileRef]:
    """공고문 후보를 순서대로 최대 2개: 이름에 '공고문·모집공고'가 든 파일 → 선호 형식(PDF) → 다른 형식(HWP·HWPX).
    첫 번째가 받기·읽기에 실패하면 두 번째를 시도해요."""
    usable = [f for f in files if f.notice_doc and f.ext in DOC_EXTS]
    order = {"pdf": 0, "hwp": 1, "hwpx": 1} if prefer == "pdf" else {"hwp": 0, "hwpx": 0, "pdf": 1}
    usable.sort(key=lambda f: (not NOTICE_FILE_NAME.search(f.name), order[f.ext], f.index))
    return usable[:2]


def pick_unit_lists(files: list[FileRef]) -> list[FileRef]:
    """주택목록 최대 2개: '상세'가 든 목록 먼저, 같은 목록이 엑셀·PDF로 있으면 엑셀 하나만."""
    lists = [f for f in files if f.unit_list and f.ext in TABLE_EXTS]
    lists.sort(key=lambda f: ("상세" not in f.name, f.ext not in ("xlsx", "xlsm"), f.name))
    picked, stems = [], set()
    for file in lists:
        stem = re.sub(r"^\s*[\d\-.]+\s*|\.[A-Za-z0-9]+$", "", file.name).strip()
        if stem not in stems:
            stems.add(stem)
            picked.append(file)
    return picked[:2]
```

### 5-8. 해시 — `core/versioning.py`

```python
"""원본이 바뀌었는지 판단하는 해시. 본문 + 첨부 파일 해시가 같으면 같은 버전이에요."""

import hashlib


def sha256_hex(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def content_hash(body_text: str, file_hashes: list[str]) -> str:
    digest = hashlib.sha256(body_text.encode("utf-8"))
    for value in sorted(file_hashes):
        digest.update(value.encode("ascii"))
    return digest.hexdigest()


def list_hash(keys: list[str]) -> str:
    """목록 1페이지가 지난번과 같은지 보는 해시 (글번호·제목·날짜·상태). 조회수는 매번 바뀌어서 넣지 않아요."""
    return hashlib.sha256("\n".join(keys).encode("utf-8")).hexdigest()
```

### 5-9. HWP 변환 — `core/documents/hwp.py`

HWP는 pyhwp의 `hwp5html`로 HTML로 바꿔서 읽어요. HTML로 바꾸면 표의 합쳐진 칸까지 살아 있어서, PDF와 같은 방법으로 표를 읽을 수 있어요. 바꿀 수 없으면 `hwp5txt`로 글자만 뽑아요.

```python
"""HWP 변환. pyhwp의 hwp5html로 HTML을 만들면 표 구조(합쳐진 칸 포함)가 살아 있어요."""

import os
import shutil
import subprocess
import sys
from pathlib import Path


def tool(name: str) -> str | None:
    """pyhwp 명령 경로. 가상환경을 켜지 않고 .venv/bin/python으로 실행한 경우도 찾아요."""
    sibling = os.path.join(os.path.dirname(sys.executable), name)
    return shutil.which(name) or (sibling if os.path.exists(sibling) else None)


def _last_error(stderr: bytes) -> str:
    lines = [line for line in (stderr or b"").decode("utf-8", errors="replace").splitlines() if line.strip()]
    return lines[-1].strip()[:150] if lines else ""


def hwp_to_html(path: Path) -> tuple[str | None, str]:
    """(HTML, 오류 문구). 한 번 바꾼 결과는 같은 폴더에 남겨 다시 쓰지 않아요."""
    out = path.with_suffix(path.suffix + ".html")
    if out.exists() and out.stat().st_size > 200:
        return out.read_text(encoding="utf-8", errors="replace"), ""
    command = tool("hwp5html")
    if not command:
        return None, "hwp5html 없음 (uv add pyhwp six)"
    try:
        done = subprocess.run([command, "--html", "--output", str(out), str(path)], capture_output=True, timeout=180)
    except subprocess.TimeoutExpired:
        return None, "HWP→HTML 변환 시간 초과"
    if done.returncode == 0 and out.exists() and out.stat().st_size > 200:
        return out.read_text(encoding="utf-8", errors="replace"), ""
    return None, _last_error(done.stderr)


def hwp_to_plain_text(path: Path) -> tuple[str | None, str]:
    """HTML 변환이 안 될 때의 예비 수단 (표 구조 없이 글자만)."""
    command = tool("hwp5txt")
    if not command:
        return None, "hwp5txt 없음 (uv add pyhwp six)"
    try:
        done = subprocess.run([command, str(path)], capture_output=True, timeout=180)
    except subprocess.TimeoutExpired:
        return None, "HWP 변환 시간 초과"
    text = done.stdout.decode("utf-8", errors="replace")
    if done.returncode == 0 and len(text.strip()) >= 200:
        return text, ""
    return None, _last_error(done.stderr)
```

### 5-10. 공고문 글자 추출 — `core/documents/text.py`

형식마다 읽는 도구가 달라요. 읽은 글자가 200자보다 적으면 실패로 봐요(스캔본 PDF 등). 실패하면 공고문 후보 두 번째 파일을 시도해요.

| 형식 | 도구 | 방법 |
| --- | --- | --- |
| PDF | pdfplumber | 쪽마다 글자 + 표를 `칸 \| 칸`으로 |
| HWPX | 파이썬 기본(zip) | 압축 안의 `Contents/section*.xml`에서 글자, 표(`hp:tbl`)는 `칸 \| 칸`으로 |
| HWP | pyhwp | `hwp5html`로 HTML → `body_text`. 안 되면 `hwp5txt` (표 구조 없음) |

```python
"""공고문 원본에서 글자를 뽑아요. 표는 행·열을 '칸 | 칸'으로 살려서 AI 추출 단계가 표를 읽을 수 있게 해요."""

import re
import tempfile
import zipfile
from html import unescape
from pathlib import Path

from mujuthaek_collector.core.documents.hwp import hwp_to_html, hwp_to_plain_text
from mujuthaek_collector.core.html import body_text, soup

MIN_CHARS = 200  # 이보다 글자가 적으면 읽기 실패로 봐요 (스캔본 PDF 등)


def _table_lines(rows: list[list[str | None]]) -> str:
    return "\n".join(" | ".join(re.sub(r"\s+", " ", cell or "").strip() for cell in row) for row in rows if any(row))


def pdf_text(path: Path) -> tuple[str | None, str]:
    import pdfplumber

    parts = []
    with pdfplumber.open(path) as pdf:
        for number, page in enumerate(pdf.pages, 1):
            parts.append(f"--- {number}쪽 ---\n{page.extract_text() or ''}")
            for table in page.extract_tables() or []:
                parts.append("[표]\n" + _table_lines(table))
    text = "\n".join(parts)
    if len(re.sub(r"\s|---\s*\d+쪽\s*---", "", text)) < MIN_CHARS:
        return None, "PDF에 글자가 거의 없음 (스캔본 가능성)"
    return text, "PDF 텍스트·표"


def hwpx_text(path: Path) -> tuple[str | None, str]:
    with zipfile.ZipFile(path) as archive:
        sections = sorted(n for n in archive.namelist() if re.match(r"Contents/section\d+\.xml", n))
        xml = "".join(archive.read(n).decode("utf-8", errors="replace") for n in sections)

    def table_to_text(match: re.Match) -> str:
        rows = []
        for row in re.findall(r"<hp:tr\b[\s\S]*?</hp:tr>", match.group(0)):
            cells = [re.sub(r"\s+", " ", unescape(re.sub(r"<[^>]+>", " ", cell))).strip() for cell in re.findall(r"<hp:tc\b[\s\S]*?</hp:tc>", row)]
            rows.append(" | ".join(cells))
        return "\n[표]\n" + "\n".join(rows) + "\n"

    xml = re.sub(r"<hp:tbl\b[\s\S]*?</hp:tbl>", table_to_text, xml)
    xml = re.sub(r"</hp:p>", "\n", xml)
    text = re.sub(r"[ \t]+", " ", unescape(re.sub(r"<[^>]+>", "", xml)))
    return (text, "HWPX 텍스트·표") if len(text.strip()) >= MIN_CHARS else (None, "HWPX에서 글자를 거의 찾지 못함")


def hwp_text(path: Path) -> tuple[str | None, str]:
    html, error = hwp_to_html(path)
    if html:
        text = body_text(soup(html).body or soup(html))
        if len(text.strip()) >= MIN_CHARS:
            return text, "HWP 텍스트·표"
    text, fallback_error = hwp_to_plain_text(path)
    if text:
        return text, "HWP 텍스트 (표 구조 없음)"
    return None, f"HWP 변환 실패: {fallback_error or error}"


def extract_text(data: bytes, ext: str) -> tuple[str | None, str]:
    """(텍스트, 상태). 실패하면 텍스트는 None이고 상태에 이유가 들어가요."""
    readers = {"pdf": pdf_text, "hwpx": hwpx_text, "hwp": hwp_text}
    if ext not in readers:
        return None, f"{ext or '알 수 없는'} 형식은 읽지 않음"
    with tempfile.TemporaryDirectory() as folder:
        path = Path(folder) / f"source.{ext}"
        path.write_bytes(data)
        try:
            return readers[ext](path)
        except Exception as error:  # noqa: BLE001 — 손상된 파일 등은 '읽지 못함'으로 기록하고 넘어감
            return None, f"{ext.upper()} 읽기 실패 ({type(error).__name__})"
```

### 5-11. 표 → 호별 임대조건 — `core/documents/tables.py`

기관마다 표 모양이 다 달라서 **머리글 이름으로 칸의 뜻**을 찾아요. 실제 공고에서 확인한 경우를 처리해요.

| 경우 | 처리 |
| --- | --- |
| 머리글이 두 줄 (임대조건 아래 보증금·월임대료) | 윗줄·아랫줄을 합쳐 "임대조건 보증금"처럼 읽음 |
| 가로로 합쳐진 머리글 칸 | 왼쪽 머리글을 이어받음 |
| 세로로 합쳐진 값 (같은 주택형의 아래 행) | 면적·주택형·단지·주소는 위 행 값을 이어받음 |
| "단위: 천원", "만원" | 금액에 1,000·10,000을 곱함 (머리글에 있으면 머리글 기준) |
| 다음 쪽으로 이어지는 표 | 앞 머리글을 그대로 씀 |
| 소계·합계 행 | 건너뜀 |
| 전용·공용·공급·계약 면적이 같이 있는 표 | "전용"이 든 칸만 전용면적으로 |
| 말이 안 되는 값 (보증금 50만 원 미만 등) | 값을 비우고 `check`에 남김. 절반 넘게 이상하면 호별 표가 아니라고 보고 버림 |
| '호수' 칸이 숫자뿐 | 호실이 아니라 공급 호수로 봄 |

```python
"""공고문·주택목록의 표에서 호별 임대조건(전용면적·보증금·월임대료·공급 대상 등)을 뽑아요.

기관마다 표 모양이 달라서 머리글 이름으로 칸의 뜻을 찾아요. 두 줄 머리글, 가로·세로로 합쳐진 칸,
'단위: 천원' 같은 금액 단위, 다음 쪽으로 이어지는 표를 처리해요. 말이 안 되는 값은 비우고 check에 남겨요.
"""

import re
import tempfile
import zipfile
from html import unescape
from pathlib import Path

from mujuthaek_collector.core.documents.hwp import hwp_to_html
from mujuthaek_collector.core.html import soup, table_grid

Table = tuple[int, str, list[list]]  # (쪽 번호, 그 쪽의 글자, 행들)

UNIT_FIELDS = [  # (표준 항목, 머리글 패턴) — 위에 있는 항목부터 맞춰봐요
    (
        "count",
        r"공급\s*호\s*수|공급\s*세대|모집\s*호\s*수|모집\s*인원|금회\s*(?:공급|모집)|모집\s*세대|공급\s*수|^\s*세대\s*수\s*$",
    ),
    ("target", r"공급\s*대상|입주\s*대상|대상\s*계층|^\s*계층\s*$"),
    ("rent", r"월\s*임대료|월\s*세|임대료"),
    ("deposit", r"보증금"),
    ("area", r"전용|면적"),
    ("unit", r"동\s*·?\s*호|호\s*실|세대\s*번호|^\s*호\s*수?\s*$"),
    ("address", r"주소|소재지|지번|임대\s*대상\s*명"),
    ("complex", r"단지|지구\s*명|주택\s*명|건물\s*명|명칭"),
    ("district", r"자치구|시군구|소재\s*구|^\s*구\s*$|지역"),
    ("type", r"주택\s*형|타입|형별|유형|평형"),
    ("floor", r"^\s*층\s*$|층\s*수|해당\s*층"),
    ("rooms", r"방\s*수|방\s*개수|구조"),
    ("elevator", r"승강기|엘리베이터"),
    ("parking", r"주차"),
]
NOT_AREA = re.compile(r"공용|공급\s*면적|계약|합계|대지|공유")
FILL_DOWN = {"area", "type", "complex", "district", "address"}  # 세로로 합쳐진 칸은 위 행 값을 이어받음
KEY_FIELDS = {"area", "deposit", "rent", "unit", "address", "complex", "type", "count"}
IDENTITY_FIELDS = {"unit", "address", "complex", "type", "area"}
SANE = {"deposit_won": (500_000, 3_000_000_000), "rent_won": (10_000, 5_000_000), "area_m2": (5, 300)}


def cell_text(value) -> str:
    return re.sub(r"\s+", " ", str(value)).strip() if value is not None else ""


def map_header(labels: list[str]) -> dict[int, str]:
    """머리글 칸마다 표준 항목을 붙여요. 같은 항목은 처음 나온 칸 하나에만.
    면적은 '전용'이 든 칸을 먼저 쓰고, 공용·공급·계약·합계 면적 칸은 전용면적으로 쓰지 않아요."""
    mapping: dict[int, str] = {}
    used: set[str] = set()
    candidates = [i for i, label in enumerate(labels) if "전용" in label and not re.search(r"공용|보증금|임대료", label)]
    best = next((i for i in candidates if "면적" in labels[i]), candidates[0] if candidates else None)
    if best is not None:
        mapping[best], used = "area", {"area"}
    for index, label in enumerate(labels):
        if index in mapping:
            continue
        for field, pattern in UNIT_FIELDS:
            if field in used or (field == "area" and NOT_AREA.search(label)):
                continue
            if re.search(pattern, label):
                mapping[index] = field
                used.add(field)
                break
    return mapping


def is_header(row: list[str]) -> bool:
    """호별 표의 머리글: 핵심 항목 2개 이상 + 그중 하나는 호·주소·단지·주택형·면적.
    (돈 항목만 있는 전환비율표 같은 건 제외)"""
    labels = [cell_text(c) for c in row]
    numeric = sum(bool(re.fullmatch(r"[\d,.\-~ ]+", c)) for c in labels if c)
    fields = set(map_header(labels).values())
    return len(KEY_FIELDS & fields) >= 2 and bool(IDENTITY_FIELDS & fields) and numeric <= len(labels) // 3


def money_multiplier(text: str) -> int:
    if re.search(r"천\s*원", text):
        return 1000
    if re.search(r"만\s*원", text):
        return 10000
    return 1


def to_int(value: str, multiplier: int) -> int | None:
    """칸의 첫 번째 숫자만 써요. '104,454,261 / 141,561,341'처럼 숫자가 여러 개여도 이어 붙이지 않아요."""
    found = re.search(r"\d[\d,]*", value or "")
    return int(found.group(0).replace(",", "")) * multiplier if found else None


def to_float(value: str) -> float | None:
    found = re.search(r"\d+(?:\.\d+)?", (value or "").replace(",", ""))
    return float(found.group(0)) if found else None


def units_from_tables(tables: list[Table]) -> list[dict]:
    """머리글을 찾아 표준 항목으로 바꾼 호별 목록. 머리글 없이 다음 쪽으로 이어지는 표는 앞 머리글을 그대로 써요."""
    units: list[dict] = []
    header: list[str] | None = None
    mapping: dict[int, str] = {}
    multipliers: dict[int, int] = {}
    page_unit = 1
    for page, page_text, raw_rows in tables:
        unit_note = re.search(r"단위[^\n]{0,15}", page_text or "")
        page_unit = money_multiplier(unit_note.group(0)) if unit_note else page_unit
        rows = [[cell_text(c) for c in row] for row in raw_rows if row and any(cell_text(c) for c in row)]
        start = 0
        for i, row in enumerate(rows):
            if not is_header(row):
                continue
            filled, last = [], ""
            for cell in row:  # 가로로 합쳐진 칸(빈 칸)은 왼쪽 머리글을 이어받음
                last = cell or last
                filled.append(cell or last)
            labels, start = filled, i + 1
            below = rows[i + 1] if i + 1 < len(rows) else None
            two_rows = "" in row and below and len(below) == len(row) and any(below) and all(re.search(r"[가-힣A-Za-z]", c) for c in below if c)
            if two_rows:
                labels = [f"{a} {b}".strip() if b and b != a else a for a, b in zip(filled, below)]
                start = i + 2
            header, mapping = labels, map_header(labels)
            multipliers = {
                idx: money_multiplier(labels[idx]) if money_multiplier(labels[idx]) > 1 else page_unit
                for idx, field in mapping.items()
                if field in ("deposit", "rent")
            }
            break
        if header is None:
            continue
        above: dict[int, str] = {}
        for row in rows[start:]:
            if len(row) != len(header) or is_header(row):
                continue
            first = next((c for c in row if c), "")
            if re.fullmatch(r"(?:소|합|총)?\s*계|합\s*계|총\s*계", first):
                continue
            unit: dict = {"page": page}
            for idx, field in mapping.items():
                value = row[idx]
                if not value and field in FILL_DOWN and above.get(idx):
                    value = above[idx]
                above[idx] = value
                if field in ("deposit", "rent"):
                    unit[field + "_won"] = to_int(value, multipliers.get(idx, 1))
                elif field == "area":
                    unit["area_m2"] = to_float(value)
                elif field == "count":
                    unit["count"] = to_int(value, 1)
                else:
                    unit[field] = value
            raw: dict[str, str] = {}
            for number, (label, value) in enumerate(zip(header, row), 1):
                key = label or f"칸{number}"
                while key in raw:
                    key += "+"
                raw[key] = value
            unit["raw"] = raw
            for key, (low, high) in SANE.items():
                if unit.get(key) is not None and not low <= unit[key] <= high:
                    unit.setdefault("check", []).append(f"{key}={unit[key]}")
                    unit[key] = None
            if any(unit.get(k) for k in ("area_m2", "deposit_won", "rent_won", "unit", "address")):
                units.append(unit)
    unit_values = [u.get("unit", "") for u in units if u.get("unit")]
    if unit_values and all(re.fullmatch(r"[\d,]+", v) for v in unit_values):
        for u in units:  # '호수' 칸이 숫자뿐이면 호실이 아니라 공급 호수
            if u.get("unit"):
                u.setdefault("count", to_int(u.pop("unit"), 1))
    if units and sum(bool(u.get("check")) for u in units) > len(units) / 2:
        return []  # 절반 넘게 이상한 값이면 호별 표가 아니라고 보고 버림
    return units


def read_tables(data: bytes, ext: str) -> list[Table]:
    """파일에서 표를 [(쪽, 쪽 글자, 행들)]로 꺼내요."""
    with tempfile.TemporaryDirectory() as folder:
        path = Path(folder) / f"source.{ext}"
        path.write_bytes(data)
        if ext == "pdf":
            import pdfplumber

            out: list[Table] = []
            with pdfplumber.open(path) as pdf:
                for number, page in enumerate(pdf.pages, 1):
                    text = page.extract_text() or ""
                    for table in page.extract_tables() or []:
                        out.append((number, text, table))
            return out
        if ext in ("xlsx", "xlsm"):
            import openpyxl

            book = openpyxl.load_workbook(path, read_only=True, data_only=True)
            return [(i, sheet.title, [list(r) for r in sheet.iter_rows(values_only=True)]) for i, sheet in enumerate(book.worksheets, 1)]
        if ext == "hwpx":
            with zipfile.ZipFile(path) as archive:
                xml = "".join(archive.read(n).decode("utf-8", errors="replace") for n in sorted(archive.namelist()) if re.match(r"Contents/section\d+\.xml", n))
            out = []
            for table in re.findall(r"<hp:tbl\b[\s\S]*?</hp:tbl>", xml):
                rows = [
                    [unescape(re.sub(r"<[^>]+>", " ", cell)) for cell in re.findall(r"<hp:tc\b[\s\S]*?</hp:tc>", row)]
                    for row in re.findall(r"<hp:tr\b[\s\S]*?</hp:tr>", table)
                ]
                out.append((1, unescape(re.sub(r"<[^>]+>", " ", xml))[:2000], rows))
            return out
        if ext == "hwp":
            html, _ = hwp_to_html(path)
            if not html:
                return []
            document = soup(html)
            out = []
            for table in document.find_all("table"):
                if table.find("table") is not None:
                    continue  # 안에 다른 표가 없는 표만
                context = " ".join(s.strip() for s in table.find_all_previous(string=True, limit=60)[::-1])[-400:]
                out.append((1, context, table_grid(table)))
            return out
    return []


def summarize(units: list[dict]) -> str:
    """로그용 한 줄 요약: '15행, 전용 59.34㎡~59.98㎡, 보증금 72,000,000원~112,000,000원'."""

    def span(key: str, unit: str) -> str | None:
        values = [u[key] for u in units if u.get(key)]
        if not values:
            return None
        low, high = min(values), max(values)
        fmt = (lambda v: f"{v:,.2f}{unit}") if key == "area_m2" else (lambda v: f"{v:,}{unit}")
        return fmt(low) if low == high else f"{fmt(low)}~{fmt(high)}"

    parts = [f"{len(units)}행"]
    for key, label, unit in (("area_m2", "전용", "㎡"), ("deposit_won", "보증금", "원"), ("rent_won", "월임대료", "원")):
        value = span(key, unit)
        if value:
            parts.append(f"{label} {value}")
    return ", ".join(parts)
```

### 5-12. S3 원본 보관 — `core/file_store.py`

받은 원본 파일을 S3(로컬은 MinIO)에 올려요. 파이프라인은 `FileStore` 규격(`put`, `delete`)만 알아서, 테스트에서는 메모리 저장소로 바꿔 끼워요.

| 항목 | 규칙 |
| --- | --- |
| 위치 | `raw/<출처>/<글 키>/v<버전>/<순번>-<파일명>` (예: `raw/ih/notice-123/v1/00-공고문_최종_.pdf`) |
| 긴 글자 | AI에 넘길 전체 글자가 20만 자를 넘으면 `text/<출처>/<글 키>/v<버전>.txt`에 따로 둬요 |
| 보관 기한 | 마감일(없으면 게시일, 둘 다 없으면 오늘) + 6개월. 제목에 "예비입주자"가 있으면 1년 |
| 기한이 지나면 | `cleanup` 명령이 파일만 지워요. 기관 다운로드 주소·해시·추출한 글자·호별 표는 DB에 계속 남아요 |

```python
"""원본 파일 보관 (로컬은 MinIO, AWS로 옮기면 S3). S3_ENDPOINT를 빈 값으로 주면 AWS S3를 써요.

S3 위치: raw/<출처>/<글 키>/v<버전>/<순번>-<파일명>
보관 기한: 마감일(없으면 게시일) + 6개월, 예비입주자 모집은 1년. 기한이 지나면 cleanup 명령이 파일만 지우고,
기관 다운로드 주소·해시·추출한 글자·호별 표는 DB에 계속 남아요.
"""

import re
from datetime import date
from typing import Protocol

CONTENT_TYPES = {
    "pdf": "application/pdf",
    "hwp": "application/x-hwp",
    "hwpx": "application/hwp+zip",
    "xlsx": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
    "xlsm": "application/vnd.ms-excel.sheet.macroEnabled.12",
    "txt": "text/plain; charset=utf-8",
}


class FileStore(Protocol):
    def put(self, key: str, data: bytes, content_type: str) -> str: ...

    def delete(self, key: str) -> None: ...


class S3FileStore:
    def __init__(self, bucket: str, endpoint: str | None = None, access_key: str | None = None, secret_key: str | None = None):
        import boto3

        self._bucket = bucket
        self._s3 = boto3.client("s3", endpoint_url=endpoint, aws_access_key_id=access_key, aws_secret_access_key=secret_key)

    def put(self, key: str, data: bytes, content_type: str) -> str:
        self._s3.put_object(Bucket=self._bucket, Key=key, Body=data, ContentType=content_type)
        return key

    def delete(self, key: str) -> None:
        self._s3.delete_object(Bucket=self._bucket, Key=key)


def safe_part(text: str, limit: int = 80) -> str:
    """S3 키에 쓸 수 있게: 슬래시·공백·특수문자는 _로. 한글은 그대로 둬요."""
    cleaned = re.sub(r"[^0-9A-Za-z가-힣._\-]+", "_", text).strip("_")
    return cleaned[:limit] or "file"


def object_key(source_code: str, post_key: str, version: int, idx: int, name: str) -> str:
    return f"raw/{source_code}/{safe_part(post_key)}/v{version}/{idx:02d}-{safe_part(name, 120)}"


def text_key(source_code: str, post_key: str, version: int) -> str:
    """AI에 넘길 전체 글자가 너무 길 때 따로 두는 위치."""
    return f"text/{source_code}/{safe_part(post_key)}/v{version}.txt"


def content_type(ext: str) -> str:
    return CONTENT_TYPES.get(ext, "application/octet-stream")


def add_months(day: date, months: int) -> date:
    month = day.month - 1 + months
    year, month = day.year + month // 12, month % 12 + 1
    last_day = [31, 29 if year % 4 == 0 and (year % 100 != 0 or year % 400 == 0) else 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31][month - 1]
    return date(year, month, min(day.day, last_day))


def stored_until(title: str, deadline_on: date | None, posted_on: date | None, today: date) -> date:
    """파일 보관 기한: 마감일(없으면 게시일, 둘 다 없으면 오늘) + 6개월. 예비입주자 모집은 1년."""
    base = deadline_on or posted_on or today
    return add_months(base, 12 if re.search(r"예비\s*입주자", title) else 6)
```

### 5-13. 이벤트 만들기 — `core/publisher.py`

`raw.notice.collected` 이벤트를 만들어요. 형식은 `contracts/events/raw.notice.collected.v1.json`이고, 테스트 `test_contract.py`가 실제 스키마로 검사해요. 이벤트는 storage.py의 `save_version`이 저장과 **같은 트랜잭션**에서 아웃박스에 적고, 발행기(`relay`)가 RabbitMQ로 보내요. 그래서 "저장은 됐는데 이벤트가 사라지는" 일이 없어요.

| 이벤트 칸 | 값 |
| --- | --- |
| `field` | 항상 `HOUSING` (이 수집기는 주거만) |
| `kind` | `NOTICE`, `CORRECTION`, `FOLLOW_UP` |
| `supersedesPostId` | 정정공고·후속 안내가 가리키는 원래 모집공고 |
| `text` | AI 추출에 넘길 전체 글자(pipeline.py의 `compose_full_text`). 20만 자를 넘으면 앞부분만 넣고 `textKey`에 전체 위치 |
| `units` | 규칙으로 읽은 호별 임대조건 (칸 이름은 camelCase: `houseType`, `areaM2`, `depositWon` …) |
| `files` | 받은 첨부의 이름, 기관 다운로드 주소, SHA-256 |
| `reprocess` | 과거 공고 재처리면 `true` (사용자 알림을 보내지 않음). 정기 수집은 항상 `false` |

```python
"""수집 이벤트(raw.notice.collected) 만들기. 형식은 contracts/events/raw.notice.collected.v1.json이에요.

이벤트는 storage.save_version이 저장과 같은 트랜잭션에서 아웃박스에 적고, 발행기(relay)가 RabbitMQ로 보내요.
"""

from datetime import date
from typing import Any
from uuid import UUID

from mujuthaek_platform.events import new_event

EVENT_TYPE = "raw.notice.collected"
PRODUCER = "collector"
MAX_TEXT_CHARS = 200_000  # 이보다 길면 앞부분만 이벤트에 넣고 전체는 S3(textKey)에 둬요

UNIT_KEYS = {  # raw_units 칸 이름 → 이벤트 칸 이름 (camelCase)
    "page": "page",
    "complex": "complex",
    "district": "district",
    "address": "address",
    "unit": "unit",
    "floor": "floor",
    "type": "houseType",
    "target": "targetGroup",
    "rooms": "rooms",
    "area_m2": "areaM2",
    "deposit_won": "depositWon",
    "rent_won": "rentWon",
    "count": "supplyCount",
    "elevator": "elevator",
    "parking": "parking",
    "source_file": "sourceFile",
}


def unit_payload(unit: dict[str, Any]) -> dict[str, Any]:
    out = {UNIT_KEYS[k]: v for k, v in unit.items() if k in UNIT_KEYS and v not in (None, "")}
    if unit.get("check"):
        out["checks"] = unit["check"]
    return out


def build_collected_event(
    *,
    raw_post_id: UUID,
    version: int,
    source_code: str,
    provider: str,
    kind: str,
    title: str,
    posted_on: date | None,
    detail_url: str | None,
    parent_post_id: UUID | None,
    full_text: str,
    text_key: str | None,
    units: list[dict[str, Any]],
    files: list[dict[str, Any]],
    region_code: str | None = None,
    reprocess: bool = False,
) -> dict[str, Any]:
    payload = {
        "rawPostId": str(raw_post_id),
        "version": version,
        "sourceCode": source_code,
        "provider": provider,
        "regionCode": region_code,
        "field": "HOUSING",
        "kind": kind,
        "title": title,
        "postedOn": posted_on.isoformat() if posted_on else None,
        "detailUrl": detail_url,
        "supersedesPostId": str(parent_post_id) if parent_post_id else None,
        "text": full_text[:MAX_TEXT_CHARS],
        "textKey": text_key,
        "units": [unit_payload(u) for u in units],
        "files": [{"name": f["name"], "downloadUrl": f["download_url"], "sha256": f["file_hash"]} for f in files],
        "reprocess": reprocess,
    }
    return new_event(EVENT_TYPE, PRODUCER, payload)
```

### 5-14. 수집 DB 저장 — `core/storage.py`

collector 데이터베이스 테이블에 읽고 쓰는 코드예요. 파이프라인은 `Store` 규격만 알고, 운영에서는 `PostgresStore`, 테스트에서는 메모리로 구현한 `MemoryStore`(`tests/fakes.py`)를 넣어요.

| 메서드 | 하는 일 |
| --- | --- |
| `start_run` / `finish_run` | 수집 회차 기록 (`crawl_runs`) |
| `board_state` / `save_board_state` | 게시판별 목록 1페이지 해시, 목록 0건 연속 횟수 (`source_boards`) |
| `find_post` / `insert_post` | 목록에서 본 글 찾기·처음 저장. 같은 `(출처, 글 키)`는 한 번만 |
| `update_list_fields` | 이미 본 글의 목록 상태·마감일만 갱신 |
| `queued_posts` | 이번에 열 글: `PENDING` 먼저, 그다음 3번 미만 실패한 `FAILED` |
| `notices_posted_on` / `recent_notices` | 후속 안내·정정공고가 가리키는 원래 모집공고 찾기 |
| `requeue_open_posts` | 새벽 정정 확인: 마감 전(또는 마감일 모름)이고 최근 90일 안의 공고를 `PENDING`으로 |
| `latest_hash` | 마지막 버전의 해시 (같으면 새 버전을 만들지 않음) |
| `save_version` | **한 트랜잭션**으로 버전 + 첨부 + 추출 글자 + 호별 표 + 글 상태 `DONE` + 아웃박스 이벤트 |
| `mark_done` / `mark_failed` | 바뀐 게 없을 때 / 실패했을 때 (`attempts` 1 증가) |
| `expired_files` / `mark_file_deleted` | 보관 기한이 지난 파일 찾기·지운 표시 (`cleanup`) |

```python
"""수집 DB 저장. 파이프라인은 Store 규격만 알고, 운영은 PostgresStore, 테스트는 MemoryStore(tests/fakes.py)를 써요.

- 글(raw_posts)은 목록에서 본 순간 한 번 저장하고, 상태(SKIPPED·PENDING·DONE·FAILED)만 바꿔요
- 새 버전은 save_version 한 번의 트랜잭션으로 저장해요: 버전 + 첨부 + 추출 글자 + 호별 표 + 글 상태 + 아웃박스 이벤트
"""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from datetime import date, timedelta
from typing import Any, Protocol
from uuid import UUID

from mujuthaek_platform import outbox
from mujuthaek_platform.ids import uuid7

MAX_ATTEMPTS = 3  # FAILED 글은 3번까지 다시 시도

SKIPPED, PENDING, DONE, FAILED = "SKIPPED", "PENDING", "DONE", "FAILED"


@dataclass
class PostRow:
    id: UUID
    source_code: str
    board_key: str
    post_key: str
    kind: str
    title: str
    posted_on: date | None
    detail_url: str | None
    list_item: dict[str, Any]
    status: str
    attempts: int = 0
    last_error: str | None = None
    list_status: str | None = None
    deadline_on: date | None = None
    parent_post_id: UUID | None = None
    latest_version: int = 0


@dataclass
class BoardState:
    last_list_hash: str = ""
    empty_runs: int = 0


@dataclass
class SavedFile:
    idx: int
    name: str
    role: str  # NOTICE_DOC, UNIT_LIST
    download_url: str
    file_hash: str
    size_bytes: int
    s3_key: str | None
    stored_until: date
    text_status: str | None = None
    text: str | None = None  # 이 파일에서 뽑은 글자 (raw_texts)

    def as_event_file(self) -> dict[str, Any]:
        return {"name": self.name, "download_url": self.download_url, "file_hash": self.file_hash}


@dataclass
class NewVersion:
    post: PostRow
    version: int
    content_hash: str
    body_text: str
    meta: dict[str, Any]
    full_text: str
    run_id: UUID | None
    files: list[SavedFile] = field(default_factory=list)
    units: list[dict[str, Any]] = field(default_factory=list)
    event: dict[str, Any] | None = None


class Store(Protocol):
    # 수집 회차
    def start_run(self, source_code: str) -> UUID: ...
    def finish_run(self, run_id: UUID, status: str, new_count: int, warnings: list[str]) -> None: ...
    # 게시판 상태
    def board_state(self, source_code: str, board_key: str) -> BoardState: ...
    def save_board_state(self, source_code: str, board_key: str, state: BoardState) -> None: ...
    # 글
    def find_post(self, source_code: str, post_key: str) -> PostRow | None: ...
    def insert_post(self, post: PostRow) -> None: ...
    def update_list_fields(self, post_id: UUID, list_status: str | None, deadline_on: date | None) -> None: ...
    def queued_posts(self, source_code: str, board_key: str, limit: int) -> list[PostRow]: ...
    def notices_posted_on(self, source_code: str, posted_on: date) -> list[PostRow]: ...
    def recent_notices(self, source_code: str, limit: int = 300) -> list[PostRow]: ...
    def requeue_open_posts(self, source_code: str, today: date, since_days: int) -> int: ...
    def latest_hash(self, post_id: UUID) -> tuple[int, str] | None: ...
    def mark_done(self, post_id: UUID) -> None: ...
    def mark_failed(self, post_id: UUID, error: str) -> None: ...
    def save_version(self, new: NewVersion) -> None: ...
    # 보관 기한 정리
    def expired_files(self, today: date, limit: int = 500) -> list[tuple[UUID, str]]: ...
    def mark_file_deleted(self, file_id: UUID) -> None: ...


POST_COLUMNS = (
    "id, source_code, board_key, post_key, kind, title, posted_on, detail_url, list_item, status, attempts, "
    "last_error, list_status, deadline_on, parent_post_id, latest_version"
)


def _row_to_post(row) -> PostRow:
    values = list(row)
    if isinstance(values[8], str):
        values[8] = json.loads(values[8])
    return PostRow(*values)


class PostgresStore:
    """collector 데이터베이스 테이블에 저장해요. 연결은 autocommit이고, 여러 문장은 transaction()으로 묶어요."""

    def __init__(self, db_url: str):
        from mujuthaek_platform import db

        self.conn = db.connect(db_url)
        self.conn.autocommit = True

    def close(self) -> None:
        self.conn.close()

    @staticmethod
    def _json(value: Any):
        from psycopg.types.json import Jsonb

        return Jsonb(value)

    # ── 수집 회차 ──────────────────────────────────────────────
    def start_run(self, source_code: str) -> UUID:
        run_id = uuid7()
        self.conn.execute("insert into crawl_runs (id, source_code) values (%s, %s)", (run_id, source_code))
        return run_id

    def finish_run(self, run_id: UUID, status: str, new_count: int, warnings: list[str]) -> None:
        self.conn.execute(
            "update crawl_runs set finished_at = now(), status = %s, new_count = %s, error = %s where id = %s",
            (status, new_count, "\n".join(warnings)[:10000] or None, run_id),
        )

    # ── 게시판 상태 ────────────────────────────────────────────
    def board_state(self, source_code: str, board_key: str) -> BoardState:
        row = self.conn.execute(
            "select last_list_hash, empty_runs from source_boards where source_code = %s and board_key = %s", (source_code, board_key)
        ).fetchone()
        return BoardState(*row) if row else BoardState()

    def save_board_state(self, source_code: str, board_key: str, state: BoardState) -> None:
        self.conn.execute(
            "insert into source_boards (source_code, board_key, last_list_hash, empty_runs, last_run_at) values (%s, %s, %s, %s, now()) "
            "on conflict (source_code, board_key) do update set last_list_hash = excluded.last_list_hash, "
            "empty_runs = excluded.empty_runs, last_run_at = now()",
            (source_code, board_key, state.last_list_hash, state.empty_runs),
        )

    # ── 글 ─────────────────────────────────────────────────────
    def find_post(self, source_code: str, post_key: str) -> PostRow | None:
        row = self.conn.execute(f"select {POST_COLUMNS} from raw_posts where source_code = %s and post_key = %s", (source_code, post_key)).fetchone()
        return _row_to_post(row) if row else None

    def insert_post(self, post: PostRow) -> None:
        self.conn.execute(
            "insert into raw_posts (id, source_code, board_key, post_key, kind, title, posted_on, detail_url, list_item, status, "
            "last_error, list_status, deadline_on, parent_post_id) values (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s) "
            "on conflict (source_code, post_key) do nothing",
            (
                post.id,
                post.source_code,
                post.board_key,
                post.post_key,
                post.kind,
                post.title,
                post.posted_on,
                post.detail_url,
                self._json(post.list_item),
                post.status,
                post.last_error,
                post.list_status,
                post.deadline_on,
                post.parent_post_id,
            ),
        )

    def update_list_fields(self, post_id: UUID, list_status: str | None, deadline_on: date | None) -> None:
        self.conn.execute(
            "update raw_posts set list_status = coalesce(%s, list_status), deadline_on = coalesce(%s, deadline_on), updated_at = now() "
            "where id = %s and (list_status is distinct from %s or deadline_on is distinct from %s)",
            (list_status, deadline_on, post_id, list_status, deadline_on),
        )

    def queued_posts(self, source_code: str, board_key: str, limit: int) -> list[PostRow]:
        rows = self.conn.execute(
            f"select {POST_COLUMNS} from raw_posts where source_code = %s and board_key = %s "
            "and (status = 'PENDING' or (status = 'FAILED' and attempts < %s)) "
            "order by (status = 'PENDING') desc, posted_on desc nulls last, created_at limit %s",
            (source_code, board_key, MAX_ATTEMPTS, limit),
        ).fetchall()
        return [_row_to_post(r) for r in rows]

    def notices_posted_on(self, source_code: str, posted_on: date) -> list[PostRow]:
        rows = self.conn.execute(
            f"select {POST_COLUMNS} from raw_posts where source_code = %s and kind = 'NOTICE' and posted_on = %s", (source_code, posted_on)
        ).fetchall()
        return [_row_to_post(r) for r in rows]

    def recent_notices(self, source_code: str, limit: int = 300) -> list[PostRow]:
        rows = self.conn.execute(
            f"select {POST_COLUMNS} from raw_posts where source_code = %s and kind = 'NOTICE' order by posted_on desc nulls last limit %s",
            (source_code, limit),
        ).fetchall()
        return [_row_to_post(r) for r in rows]

    def requeue_open_posts(self, source_code: str, today: date, since_days: int) -> int:
        """새벽 정정 확인: 아직 마감 전이거나 마감일을 모르는 최근 공고를 PENDING으로 돌려 다시 열어봐요."""
        cursor = self.conn.execute(
            "update raw_posts set status = 'PENDING', updated_at = now() where source_code = %s and status = 'DONE' "
            "and kind in ('NOTICE', 'CORRECTION') and (deadline_on is null or deadline_on >= %s) "
            "and (posted_on is null or posted_on >= %s)",
            (source_code, today, today - timedelta(days=min(since_days, 90))),
        )
        return cursor.rowcount

    def latest_hash(self, post_id: UUID) -> tuple[int, str] | None:
        row = self.conn.execute(
            "select version, content_hash from raw_post_versions where raw_post_id = %s order by version desc limit 1", (post_id,)
        ).fetchone()
        return (row[0], row[1]) if row else None

    def mark_done(self, post_id: UUID) -> None:
        self.conn.execute("update raw_posts set status = 'DONE', last_error = null, updated_at = now() where id = %s", (post_id,))

    def mark_failed(self, post_id: UUID, error: str) -> None:
        self.conn.execute(
            "update raw_posts set status = 'FAILED', attempts = attempts + 1, last_error = %s, updated_at = now() where id = %s",
            (error[:2000], post_id),
        )

    def save_version(self, new: NewVersion) -> None:
        version_id = uuid7()
        with self.conn.transaction(), self.conn.cursor() as cur:
            cur.execute(
                "insert into raw_post_versions (id, raw_post_id, version, content_hash, body_text, meta, full_text, crawl_run_id) "
                "values (%s, %s, %s, %s, %s, %s, %s, %s)",
                (version_id, new.post.id, new.version, new.content_hash, new.body_text, self._json(new.meta), new.full_text, new.run_id),
            )
            for f in new.files:
                file_id = uuid7()
                cur.execute(
                    "insert into raw_files (id, version_id, idx, name, role, download_url, file_hash, size_bytes, s3_key, stored_until, text_status) "
                    "values (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)",
                    (file_id, version_id, f.idx, f.name, f.role, f.download_url, f.file_hash, f.size_bytes, f.s3_key, f.stored_until, f.text_status),
                )
                if f.text:
                    cur.execute("insert into raw_texts (id, file_id, text) values (%s, %s, %s)", (uuid7(), file_id, f.text))
            for u in new.units:
                cur.execute(
                    "insert into raw_units (id, version_id, source_file, page, complex, district, address, unit, floor, house_type, "
                    "target_group, rooms, area_m2, deposit_won, rent_won, supply_count, elevator, parking, raw, checks) "
                    "values (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)",
                    (
                        uuid7(),
                        version_id,
                        u.get("source_file"),
                        u.get("page"),
                        u.get("complex"),
                        u.get("district"),
                        u.get("address"),
                        u.get("unit"),
                        u.get("floor"),
                        u.get("type"),
                        u.get("target"),
                        u.get("rooms"),
                        u.get("area_m2"),
                        u.get("deposit_won"),
                        u.get("rent_won"),
                        u.get("count"),
                        u.get("elevator"),
                        u.get("parking"),
                        self._json(u.get("raw", {})),
                        self._json(u.get("check", [])),
                    ),
                )
            cur.execute(
                "update raw_posts set status = 'DONE', latest_version = %s, attempts = 0, last_error = null, updated_at = now() where id = %s",
                (new.version, new.post.id),
            )
            if new.event is not None:
                outbox.add(cur, new.event)

    # ── 보관 기한 정리 ─────────────────────────────────────────
    def expired_files(self, today: date, limit: int = 500) -> list[tuple[UUID, str]]:
        rows = self.conn.execute(
            "select id, s3_key from raw_files where stored_until < %s and s3_key is not null and deleted_at is null limit %s", (today, limit)
        ).fetchall()
        return [(r[0], r[1]) for r in rows]

    def mark_file_deleted(self, file_id: UUID) -> None:
        self.conn.execute("update raw_files set s3_key = null, deleted_at = now() where id = %s", (file_id,))
```

## 6. 출처 규격과 파이프라인

수집기는 세 층으로 나눠요. 기관마다 다른 건 가운데 "읽기" 하나뿐이에요.

| 층 | 하는 일 | 코드 | 기관마다 다른가 |
| --- | --- | --- | --- |
| 받기 | 요청, robots.txt, 간격, 재시도, 차단 감지 | `core/http_client.py` | 아니요 |
| 읽기 | 목록·상세 화면 → 글 목록, 본문, 첨부 목록 | `sources/local/*.py` | **예** |
| 처리 | 분류 → 첨부 고르기·받기 → 추출 → 버전 비교 → 저장 → 이벤트 | `pipeline.py` | 아니요 |

### 6-1. 출처 규격 — `sources/base.py`

기관별 수집기는 `Source`를 상속해서 **세 가지만** 구현해요.

| 구현할 것 | 하는 일 |
| --- | --- |
| `list_request(board, page)` | 목록 N페이지 주소 (폼 POST면 `data`, 필요하면 `referer`) |
| `parse_list(board, body, page_url)` | 목록 화면(또는 JSON) → `ListItem` 목록. 목록 표 자체가 없으면 `ParseError` |
| `parse_detail(item, body)` | 상세 화면 → `Detail`(본문, 항목, 첨부 목록, 상세 화면의 호별 표). 본문 영역이 없으면 `ParseError` |

필요할 때만 바꾸는 것: `detail_request`(상세를 다른 주소·POST로 받을 때), `pre_classify`(목록의 분류 칸으로 종류를 먼저 정할 때), `legacy_tls`, `prefer_doc`.

`parse_list`와 `parse_detail`은 **네트워크를 모르는 순수 함수**예요. 문자열을 받아 데이터를 돌려주기만 해서, 저장해 둔 화면으로 바로 테스트할 수 있어요.

| 자료 | 뜻 |
| --- | --- |
| `Board` | 게시판 하나. `key`는 `raw_posts.board_key`·`source_boards.board_key`가 돼요 (예: 대전 `43`, iH `sale_lease`) |
| `Request` | 요청 하나 (주소, 폼 값, Referer) |
| `ListItem` | 목록의 글 하나. `raw_posts.list_item`에 JSON으로 그대로 저장했다가 `PENDING` 글을 다음 회차에 다시 열 때 되살려요 |
| `Detail` | 상세 화면에서 읽은 것 |
| `Fetcher` | `요청 클라이언트 규격 (운영은 PoliteClient, 테스트는 FakeClient)`: `text`, `download` |

```python
"""출처 규격. 기관별 수집기는 '주소를 어떻게 만들고, 받은 화면에서 무엇을 꺼내나'만 구현해요.

페이지 넘기기, 멈추는 조건, 분류, 첨부 고르기·받기, 문서 추출, 버전 비교, 저장, 이벤트는 모두 pipeline.py가 해요.
parse_list·parse_detail은 네트워크를 모르는 순수 함수라서 저장해 둔 화면(tests/fixtures)으로 바로 테스트할 수 있어요.
"""

from __future__ import annotations

from abc import ABC, abstractmethod
from dataclasses import asdict, dataclass, field
from datetime import date
from typing import Any, Protocol

from mujuthaek_collector.core.files import FileRef


class Fetcher(Protocol):
    """요청 클라이언트 규격. 운영은 PoliteClient, 테스트는 FakeClient가 지켜요."""

    def text(self, url: str, *, data: dict[str, str] | None = None, referer: str | None = None) -> str: ...
    def download(self, url: str, *, referer: str | None = None) -> bytes: ...


@dataclass(frozen=True)
class Board:
    key: str  # raw_posts.board_key, source_boards.board_key (예: rent, sale, 43)
    name: str  # 사람이 읽는 이름 (임대, 분양 …)
    params: dict[str, str] = field(default_factory=dict)  # 목록 주소에 붙는 값


@dataclass(frozen=True)
class Request:
    url: str
    data: dict[str, str] | None = None  # 있으면 폼 POST
    referer: str | None = None


@dataclass
class ListItem:
    board: str
    post_key: str  # 출처 안에서 유일 (게시판이 여러 개면 접두어)
    title: str
    posted_on: date | None
    detail_url: str | None  # 사람이 열어볼 주소 (이벤트의 detailUrl)
    fetch_url: str | None = None  # 상세를 받을 주소 (없으면 detail_url). SH처럼 POST 전용이면 따로
    form: dict[str, str] | None = None  # 상세를 폼 POST로 받을 때 값
    referer: str | None = None
    list_status: str | None = None  # 목록의 상태 (접수중, 모집종료 …)
    deadline_on: date | None = None
    meta: dict[str, Any] = field(default_factory=dict)  # 목록에서 읽은 항목 (유형, 지역, 분류 …)
    files: list[FileRef] = field(default_factory=list)  # 목록에서 이미 아는 첨부 (경북·경남 JSON)

    def to_json(self) -> dict[str, Any]:
        """raw_posts.list_item에 그대로 저장해요. PENDING 글을 다음 회차에 다시 열 때 from_json으로 되살려요."""
        data = asdict(self)
        data["posted_on"] = self.posted_on.isoformat() if self.posted_on else None
        data["deadline_on"] = self.deadline_on.isoformat() if self.deadline_on else None
        return data

    @classmethod
    def from_json(cls, data: dict[str, Any]) -> ListItem:
        values = dict(data)
        values["posted_on"] = date.fromisoformat(values["posted_on"]) if values.get("posted_on") else None
        values["deadline_on"] = date.fromisoformat(values["deadline_on"]) if values.get("deadline_on") else None
        values["files"] = [FileRef(**f) for f in values.get("files") or []]
        return cls(**values)


@dataclass
class Detail:
    title: str
    body_text: str
    files: list[FileRef]
    meta: dict[str, Any] = field(default_factory=dict)  # 상세 화면의 항목 (공고상태, 유형, 접수기간 …)
    units: list[dict[str, Any]] = field(default_factory=list)  # 상세 화면 표에서 읽은 호별 (GH·부산)
    posted_on: date | None = None


class Source(ABC):
    code: str  # sources.code와 같아야 해요 (sh, gh, bmc, ih, dcco, dudc, umca, gbdc, gndc)
    name: str
    provider: str  # 이벤트의 provider (SH, GH, BMC …)
    boards: list[Board]
    legacy_tls = False  # 예전 보안 연결만 받는 기관
    prefer_doc = "pdf"  # 공고문 형식 우선순위

    # ── 기관별로 구현 ──────────────────────────────────────────
    @abstractmethod
    def list_request(self, board: Board, page: int) -> Request: ...

    @abstractmethod
    def parse_list(self, board: Board, body: str, page_url: str) -> list[ListItem]:
        """목록 화면 → 글 목록. 목록 표 자체를 못 찾으면 ParseError (글이 0개인 것과 구분)."""

    @abstractmethod
    def parse_detail(self, item: ListItem, body: str) -> Detail:
        """상세 화면 → 본문·항목·첨부. 본문 영역을 못 찾으면 ParseError."""

    # ── 필요할 때만 바꿈 ───────────────────────────────────────
    def detail_request(self, item: ListItem) -> Request:
        return Request(item.fetch_url or item.detail_url or "", item.form, item.referer)

    def pre_classify(self, item: ListItem) -> str | None:
        """목록의 분류 칸으로 먼저 정할 수 있으면 종류(NOTICE·FOLLOW_UP·EXCLUDED …)를, 아니면 None(제목으로 분류)."""
        return None

    # ── 파이프라인이 부름 ─────────────────────────────────────
    def fetch_list(self, client: Fetcher, board: Board, page: int) -> list[ListItem]:
        request = self.list_request(board, page)
        body = client.text(request.url, data=request.data, referer=request.referer)
        return self.parse_list(board, body, request.url)

    def fetch_detail(self, client: Fetcher, item: ListItem) -> Detail:
        request = self.detail_request(item)
        body = client.text(request.url, data=request.data, referer=request.referer)
        return self.parse_detail(item, body)
```

### 6-2. 파이프라인 — `pipeline.py`

전체 흐름을 그대로 코드로 옮겼어요. 함수 하나가 한 단계예요.

| 함수 | 하는 일 |
| --- | --- |
| `run_source` | 회차 시작 → (정정 확인이면 마감 전 공고를 다시 `PENDING`으로) → 게시판마다 `run_board` → 회차 마무리. `BlockedError`면 `BLOCKED` |
| `run_board` | 목록 1\~N페이지. 1페이지가 비면 0건 횟수 +1(3번 연속이면 구조 변경 경고), 1페이지 해시가 지난번과 같고 밀린 글이 없으면 바로 끝. 이미 본 글은 목록 상태만 갱신, 새 글은 `register`. 한 페이지가 전부 아는 글이거나 365일 넘은 글이 나오면 다음 페이지를 보지 않아요. 그다음 밀린 글을 `detail_limit`건까지 처리하고, 밀린 글이 하나도 없을 때만 1페이지 해시를 저장 |
| `register` | 분류(`pre_classify` → 없으면 제목 `classify`). 모집공고 → `PENDING`, 정정공고 → 원래 공고를 찾아 `PENDING`, 후속 안내 → 원래 공고가 있을 때만 `PENDING`, 나머지·365일 넘은 글 → `SKIPPED`(이유를 `last_error`에) |
| `find_followup_parent` | 후속 안내 제목 속 "(공고명, 공고일)"과 같은 모집공고 |
| `find_correction_parent` | 정정 표시를 뺀 이름과 같은 가장 최근 모집공고 |
| `process_safely` | 글 하나 처리. `BlockedError`는 위로(회차 중단), 그 밖의 오류는 그 글만 `FAILED` + 경고 |
| `process_post` | 상세 → 공고문 1개(실패하면 두 번째 후보) → 주택목록 최대 2개 → 호별 표(상세 화면 + 공고문 + 주택목록) → 해시가 같으면 `DONE`만 → 다르면 S3에 올리고 한 트랜잭션으로 저장 + 이벤트 |
| `compose_full_text` | AI 추출에 넘기는 전체 글자: 제목 · 출처 · 게시일 · 주소 · \[항목\] · \[본문\] · \[공고문\] |

```python
"""출처 하나를 끝까지 수집해요 (전체 흐름 그대로).

run_source
  └─ 게시판마다
      ├─ 목록 1~N페이지 읽기 → 새 글 등록(분류) / 이미 본 글은 목록 상태만 갱신
      ├─ 밀린 글(PENDING·FAILED) + 새 글을 한 번에 detail_limit건까지 처리 (process_post)
      └─ 밀린 글이 없으면 목록 1페이지 해시 저장 (다음 회차에 같으면 바로 끝)

오류 반응: BlockedError → 출처 회차 중단(BLOCKED), ParseError·HTTP 오류 → 그 글만 FAILED, FileRejected → 그 파일만 건너뜀
"""

from __future__ import annotations

import logging
from dataclasses import dataclass, field
from datetime import date, timedelta
from uuid import UUID

import httpx

from mujuthaek_collector.config import Settings
from mujuthaek_collector.core import classify as cls
from mujuthaek_collector.core.documents.tables import read_tables, summarize, units_from_tables
from mujuthaek_collector.core.documents.text import extract_text
from mujuthaek_collector.core.file_store import FileStore, content_type, object_key, stored_until, text_key
from mujuthaek_collector.core.files import TABLE_EXTS, FileRef, pick_notice_files, pick_unit_lists
from mujuthaek_collector.core.publisher import MAX_TEXT_CHARS, build_collected_event
from mujuthaek_collector.core.storage import PENDING, SKIPPED, BoardState, NewVersion, PostRow, SavedFile, Store
from mujuthaek_collector.core.versioning import content_hash, list_hash, sha256_hex
from mujuthaek_collector.errors import BlockedError, FileRejected, ParseError
from mujuthaek_collector.sources.base import Board, Detail, Fetcher, ListItem, Source
from mujuthaek_platform.ids import uuid7

log = logging.getLogger(__name__)


@dataclass
class RunResult:
    source_code: str
    status: str = "SUCCESS"  # SUCCESS, BLOCKED, FAILED
    new_count: int = 0  # 새로 저장한 버전 수
    warnings: list[str] = field(default_factory=list)


@dataclass
class Context:
    source: Source
    client: Fetcher
    store: Store
    files: FileStore
    settings: Settings
    today: date
    run_id: UUID
    result: RunResult

    def warn(self, message: str) -> None:
        log.warning(message, extra={"source": self.source.code})
        self.result.warnings.append(message)


def run_source(
    source: Source, client: Fetcher, store: Store, files: FileStore, settings: Settings, *, recheck: bool = False, today: date | None = None
) -> RunResult:
    """출처 하나를 수집해요. recheck=True(새벽 정정 확인)면 마감 전 공고를 다시 열어 바뀌었는지 봐요."""
    today = today or date.today()
    result = RunResult(source.code)
    run_id = store.start_run(source.code)
    ctx = Context(source, client, store, files, settings, today, run_id, result)
    log.info("수집 시작", extra={"source": source.code, "recheck": recheck})
    try:
        if recheck:
            count = store.requeue_open_posts(source.code, today, settings.since_days)
            log.info("정정 확인 대상", extra={"source": source.code, "count": count})
        for board in source.boards:
            run_board(ctx, board, recheck=recheck)
    except BlockedError as error:
        result.status = "BLOCKED"
        ctx.warn(f"차단으로 이번 회차를 멈춰요: {error}")
    except Exception as error:  # noqa: BLE001 — 예상 못한 오류도 회차 기록은 남겨요
        result.status = "FAILED"
        ctx.warn(f"예상 못한 오류: {type(error).__name__}: {error}")
        log.exception("수집 실패", extra={"source": source.code})
    store.finish_run(run_id, result.status, result.new_count, result.warnings)
    log.info("수집 끝", extra={"source": source.code, "status": result.status, "new": result.new_count})
    return result


# ── 게시판 ─────────────────────────────────────────────────────
def run_board(ctx: Context, board: Board, *, recheck: bool = False) -> None:
    source, store, settings = ctx.source, ctx.store, ctx.settings
    state = store.board_state(source.code, board.key)
    queued_before = store.queued_posts(source.code, board.key, 1)
    cutoff = ctx.today - timedelta(days=settings.since_days)
    first_page_hash: str | None = None

    for page in range(1, settings.max_pages + 1):
        try:
            items = source.fetch_list(ctx.client, board, page)
        except ParseError as error:
            ctx.warn(f"[{board.name}] 목록 {page}페이지를 읽지 못해 이 게시판을 멈춰요 (구조 변경 의심): {error}")
            store.save_board_state(source.code, board.key, BoardState(state.last_list_hash, state.empty_runs + 1))
            return
        if page == 1:
            if not items:
                state.empty_runs += 1
                message = f"[{board.name}] 목록이 비어 있어요 ({state.empty_runs}회 연속)"
                ctx.warn(message + (" — 사이트 구조 변경 의심" if state.empty_runs >= settings.empty_alert else ""))
                store.save_board_state(source.code, board.key, state)
                return
            state.empty_runs = 0
            first_page_hash = list_hash([f"{i.post_key}|{i.title}|{i.posted_on}|{i.list_status or ''}" for i in items])
            if first_page_hash == state.last_list_hash and not queued_before and not recheck:
                log.info("목록 변화 없음", extra={"source": source.code, "board": board.key})
                store.save_board_state(source.code, board.key, state)
                return
        all_known = True
        for item in items:
            post = store.find_post(source.code, item.post_key)
            if post is not None:
                store.update_list_fields(post.id, item.list_status, item.deadline_on)
                continue
            all_known = False
            register(ctx, item, cutoff)
        dates = [i.posted_on for i in items if i.posted_on]
        if all_known or (dates and min(dates) < cutoff) or not items:
            break

    for post in store.queued_posts(source.code, board.key, settings.detail_limit):
        process_safely(ctx, post)

    if not store.queued_posts(source.code, board.key, 1) and first_page_hash:
        state.last_list_hash = first_page_hash  # 밀린 글이 없을 때만 저장해서, 남은 글이 있으면 다음 회차에 다시 봐요
    store.save_board_state(source.code, board.key, state)


def register(ctx: Context, item: ListItem, cutoff: date) -> None:
    """목록에서 처음 본 글을 분류해서 저장해요. 열 글은 PENDING, 안 열 글은 SKIPPED."""
    source, store = ctx.source, ctx.store
    kind = source.pre_classify(item) or cls.classify(item.title)
    status, parent, reason = SKIPPED, None, None
    if item.posted_on and item.posted_on < cutoff:
        reason = f"{ctx.settings.since_days}일 넘은 글"
    elif kind == cls.NOTICE:
        status = PENDING
    elif kind == cls.CORRECTION:
        status, parent = PENDING, find_correction_parent(store, source.code, item.title)
    elif kind == cls.FOLLOW_UP:
        parent = find_followup_parent(store, source.code, item.title)
        if parent is not None:
            status = PENDING
        else:
            reason = "원래 모집공고를 찾지 못한 후속 안내"
    else:
        reason = "모집공고가 아닌 글"
    store.insert_post(
        PostRow(
            id=uuid7(),
            source_code=source.code,
            board_key=item.board,
            post_key=item.post_key,
            kind=kind,
            title=item.title,
            posted_on=item.posted_on,
            detail_url=item.detail_url,
            list_item=item.to_json(),
            status=status,
            last_error=reason,
            list_status=item.list_status,
            deadline_on=item.deadline_on,
            parent_post_id=parent.id if parent else None,
        )
    )


def find_followup_parent(store: Store, source_code: str, title: str) -> PostRow | None:
    """후속 안내 제목 속 '(공고명, 공고일)'과 같은 모집공고."""
    ref = cls.title_ref(title)
    if ref is None:
        return None
    return next((p for p in store.notices_posted_on(source_code, ref.posted_on) if cls.same_notice(ref, p.title, p.posted_on)), None)


def find_correction_parent(store: Store, source_code: str, title: str) -> PostRow | None:
    """정정공고 이름(정정 표시를 뺀 것)과 같은 가장 최근 모집공고."""
    base = cls.correction_base(title)
    if not base:
        return None
    for post in store.recent_notices(source_code):
        own = cls.norm_name(post.title)
        if own and (own == base or own in base or base in own):
            return post
    return None


# ── 글 하나 ────────────────────────────────────────────────────
def process_safely(ctx: Context, post: PostRow) -> None:
    try:
        if process_post(ctx, post):
            ctx.result.new_count += 1
    except BlockedError:
        raise  # 출처 회차를 멈춰요. 이 글은 PENDING·FAILED 그대로 남아 다음 회차에 먼저 처리돼요
    except (ParseError, httpx.HTTPError) as error:
        ctx.store.mark_failed(post.id, f"{type(error).__name__}: {error}")
        ctx.warn(f"[{post.post_key}] {post.title[:40]} — 상세를 읽지 못했어요: {error}")
    except Exception as error:  # noqa: BLE001 — S3·DB 오류 등. 그 글만 FAILED로 두고 다음 글로 가요
        ctx.store.mark_failed(post.id, f"{type(error).__name__}: {error}")
        ctx.warn(f"[{post.post_key}] {post.title[:40]} — 저장하지 못했어요: {type(error).__name__}: {error}")
        log.exception("글 처리 실패", extra={"source": ctx.source.code, "post": post.post_key})


def process_post(ctx: Context, post: PostRow) -> bool:
    """상세 → 첨부 → 추출 → 버전 비교 → 저장·이벤트. 새 버전을 저장했으면 True."""
    source, client = ctx.source, ctx.client
    item = ListItem.from_json(post.list_item)
    detail = source.fetch_detail(client, item)
    candidates = detail.files or item.files
    referer = item.detail_url or item.referer

    saved: list[tuple[SavedFile, bytes]] = []  # (DB에 저장할 정보, S3에 올릴 원본)
    notice_name, notice_text = None, None
    units: list[dict] = [dict(u, source_file="상세 화면") for u in detail.units]
    keep_until = stored_until(post.title, post.deadline_on, post.posted_on, ctx.today)

    for file in pick_notice_files(candidates, source.prefer_doc):  # 공고문: 첫 번째가 실패하면 두 번째
        data = download(ctx, file, referer)
        if data is None:
            continue
        text, status = extract_text(data, file.ext)
        saved.append((make_saved(file, "NOTICE_DOC", data, keep_until, status, text), data))
        if file.ext in TABLE_EXTS:
            units += [dict(u, source_file=file.name) for u in units_from_tables(read_tables(data, file.ext))]
        if text:
            notice_name, notice_text = file.name, text
            break
        ctx.warn(f"[{post.post_key}] 공고문을 읽지 못했어요 ({file.name}): {status}")

    for file in pick_unit_lists(candidates):  # 주택목록: 엑셀 우선 최대 2개
        data = download(ctx, file, referer)
        if data is None:
            continue
        found = units_from_tables(read_tables(data, file.ext))
        saved.append((make_saved(file, "UNIT_LIST", data, keep_until, f"호별 {len(found)}행", None), data))
        units += [dict(u, source_file=file.name) for u in found]

    if units:
        log.info("호별 표", extra={"source": source.code, "post": post.post_key, "summary": summarize(units)})

    body = detail.body_text
    new_hash = content_hash(body, [f.file_hash for f, _ in saved])
    latest = ctx.store.latest_hash(post.id)
    if latest and latest[1] == new_hash:
        ctx.store.mark_done(post.id)  # 바뀐 게 없음 (새벽 정정 확인에서 대부분 여기로)
        return False
    version = (latest[0] if latest else 0) + 1

    for f, data in saved:  # 원본은 DB 트랜잭션 전에 S3에 올려요 (실패하면 그 글은 다음 회차에 다시 시도)
        f.s3_key = ctx.files.put(object_key(source.code, post.post_key, version, f.idx, f.name), data, content_type(ext_of(f.name)))

    meta = {**item.meta, **detail.meta}
    if item.list_status:
        meta.setdefault("목록상태", item.list_status)
    full_text = compose_full_text(source, post, item, detail, meta, notice_name, notice_text)
    long_text_key = None
    if len(full_text) > MAX_TEXT_CHARS:
        long_text_key = ctx.files.put(text_key(source.code, post.post_key, version), full_text.encode("utf-8"), content_type("txt"))

    event = build_collected_event(
        raw_post_id=post.id,
        version=version,
        source_code=source.code,
        provider=source.provider,
        kind=post.kind,
        title=post.title,
        posted_on=post.posted_on,
        detail_url=post.detail_url,
        parent_post_id=post.parent_post_id,
        full_text=full_text,
        text_key=long_text_key,
        units=units,
        files=[f.as_event_file() for f, _ in saved],
        reprocess=False,
    )
    ctx.store.save_version(
        NewVersion(
            post=post,
            version=version,
            content_hash=new_hash,
            body_text=body,
            meta=meta,
            full_text=full_text,
            run_id=ctx.run_id,
            files=[f for f, _ in saved],
            units=units,
            event=event,
        )
    )
    log.info("새 버전 저장", extra={"source": source.code, "post": post.post_key, "version": version, "files": len(saved), "units": len(units)})
    return True


def download(ctx: Context, file: FileRef, referer: str | None) -> bytes | None:
    if file.personal:
        return None  # 명단 파일은 받지 않아요 (pick 단계에서 이미 빠지지만 한 번 더 막음)
    try:
        return ctx.client.download(file.url, referer=referer)
    except FileRejected as error:
        ctx.warn(f"첨부를 받지 않았어요 ({file.name}): {error}")
    except httpx.HTTPError as error:
        ctx.warn(f"첨부를 받지 못했어요 ({file.name}): {error}")
    return None


def make_saved(file: FileRef, role: str, data: bytes, keep_until: date, status: str | None, text: str | None) -> SavedFile:
    return SavedFile(
        idx=file.index,
        name=file.name,
        role=role,
        download_url=file.url,
        file_hash=sha256_hex(data),
        size_bytes=len(data),
        s3_key=None,
        stored_until=keep_until,
        text_status=status,
        text=text,
    )


def ext_of(name: str) -> str:
    return FileRef(name, "", 0).ext


def compose_full_text(source: Source, post: PostRow, item: ListItem, detail: Detail, meta: dict, notice_name: str | None, notice_text: str | None) -> str:
    """AI 추출(extraction)에 넘기는 전체 글자: 제목·게시 정보·항목·본문·공고문 순서."""
    lines = [
        f"제목: {post.title}",
        f"출처: {source.name} ({post.board_key})",
        f"게시일: {post.posted_on or detail.posted_on or ''}",
        f"주소: {post.detail_url or ''}",
    ]
    if meta:
        lines.append("[항목]")
        lines += [f"{key}: {value}" for key, value in meta.items() if value not in (None, "", [], {})]
    lines += ["[본문]", detail.body_text or "(본문 없음)"]
    if notice_text:
        lines += [f"[공고문: {notice_name}]", notice_text]
    return "\n".join(lines)
```

```python
"""SH 서울주택도시공사 — 주택임대 게시판.

목록  GET  https://www.i-sh.co.kr/app/lay2/program/S48T1581C563/www/brd/m_247/list.do?multi_itm_seq=2&page=N
      행: [번호, 제목(getDetailView('글번호')), 담당부서, 등록일, 조회수]. 번호 칸이 숫자가 아니면 상단 고정 공지
상세  POST https://www.i-sh.co.kr/app/lay2/program/S48T1581C563/www/brd/m_247/view.do
      폼 값: page, seq, multi_itm_seq, multi_itm_seqsStr (목록과 같은 세션, 목록 주소를 Referer로). 본문은 td.cont
첨부  상세의 첨부 영역은 파일마다 [형식 아이콘][파일명 a onclick=existFile('n')][미리보기 a href=htmlConverter.do?...] 순서.
      미리보기 값으로 원본 주소를 만들어요:
      htmlConverter.do?brd_id=B&seq=S&data_tp=T&file_seq=N → https://www.i-sh.co.kr/app/com/file/innoFD.do?brdId=B&seq=S&fileTp=T&fileSeq=N
      (/upload 경로는 robots.txt 금지라, 그쪽으로 넘겨지면 PoliteClient가 FileRejected로 막아요)
주의  페이지에 NetFunnel 대기 스크립트가 있어요. 대기 화면만 오면 PoliteClient가 BlockedError로 회차를 멈춰요.
"""

import re
import urllib.parse

from mujuthaek_collector.core.files import FileRef
from mujuthaek_collector.core.html import abs_url, body_text, parse_date, query_of, soup, text_of
from mujuthaek_collector.errors import ParseError
from mujuthaek_collector.sources.base import Board, Detail, ListItem, Request, Source

BASE = "https://www.i-sh.co.kr"
BOARD_PATH = "/app/lay2/program/S48T1581C563/www/brd/m_247"
LIST_URL = f"{BASE}{BOARD_PATH}/list.do"
VIEW_URL = f"{BASE}{BOARD_PATH}/view.do"
DOWNLOAD_URL = f"{BASE}/app/com/file/innoFD.do"
SEQ = re.compile(r"getDetailView\(\s*['\"]?(\d+)|view\.do[^\"']*?[?&]seq=(\d+)")
BODY_SELECTORS = ["td.cont", "div.view_cont", "div.viewCont", "div.board_view", "div.bbs_view", "div.view_con", "div.cont_view"]


class ShSource(Source):
    code = "sh"
    name = "SH 서울주택도시공사"
    provider = "SH"
    boards = [Board("rent", "주택임대", {"multi_itm_seq": "2"})]

    def list_request(self, board: Board, page: int) -> Request:
        return Request(f"{LIST_URL}?" + urllib.parse.urlencode({**board.params, "page": page}))

    def parse_list(self, board: Board, body: str, page_url: str) -> list[ListItem]:
        doc = soup(body)
        tbody = doc.find("tbody")
        if tbody is None:
            raise ParseError("SH 목록 표(tbody)를 찾지 못했어요")
        items = []
        for tr in tbody.find_all("tr"):
            found = SEQ.search(str(tr))
            if not found:
                continue
            seq = found.group(1) or found.group(2)
            cells = [text_of(td) for td in tr.find_all("td")]
            anchor = tr.find("a")
            if anchor is not None:
                for badge in anchor.select("span[class*=icoNew], span[class*=new]"):
                    badge.decompose()  # 제목 옆 'NEW' 표시
            title = text_of(anchor) or (cells[1] if len(cells) > 1 else "")
            posted = next((parse_date(c) for c in cells if re.fullmatch(r"\d{4}[-.]\d{2}[-.]\d{2}", c)), None)
            items.append(
                ListItem(
                    board=board.key,
                    post_key=seq,
                    title=title,
                    posted_on=posted,
                    detail_url=f"{LIST_URL}?multi_itm_seq={board.params['multi_itm_seq']}",  # POST 전용이라 사람에게는 목록 주소로 안내
                    fetch_url=VIEW_URL,
                    form={"page": "1", "seq": seq, "multi_itm_seq": board.params["multi_itm_seq"], "multi_itm_seqsStr": ""},
                    referer=page_url,
                    meta={"담당부서": cells[2] if len(cells) > 2 else "", "상단고정": bool(cells) and not cells[0].isdigit()},
                )
            )
        return items

    def parse_detail(self, item: ListItem, body: str) -> Detail:
        doc = soup(body)
        content = next((node for node in (doc.select_one(s) for s in BODY_SELECTORS) if node is not None), None)
        if content is None:
            raise ParseError(f"SH 상세 본문(td.cont)을 찾지 못했어요: {item.post_key}")
        return Detail(title=item.title, body_text=body_text(content), files=self.parse_files(doc))

    @staticmethod
    def parse_files(doc) -> list[FileRef]:
        """[파일명 existFile('n')] 다음에 오는 [미리보기 htmlConverter.do]의 값으로 원본 주소를 만들어요."""
        files: list[FileRef] = []
        pending_name: str | None = None
        for anchor in doc.find_all("a"):
            onclick, href = anchor.get("onclick") or "", anchor.get("href") or ""
            if re.search(r"existFile\(", onclick):
                pending_name = text_of(anchor)[:120]
                continue
            if "htmlConverter.do" in href and pending_name:
                query = query_of(abs_url(BASE, href))
                if all(k in query for k in ("brd_id", "seq", "file_seq")):
                    params = {"brdId": query["brd_id"], "seq": query["seq"], "fileTp": query.get("data_tp", "A"), "fileSeq": query["file_seq"]}
                    files.append(FileRef(pending_name, f"{DOWNLOAD_URL}?" + urllib.parse.urlencode(params), len(files)))
                pending_name = None
        return files
```

```python
            Board("rent", "임대", {"path": "/sb/sr/sr7150/selectPbancRentHouseList.do"}),
            Board("buy", "매입임대", {"path": "/sb/sr/sr7155/selectPbancRentHouseList.do"}),

    "bmc": {

DATE = re.compile(r"\d{4}-\d{2}-\d{2}")
STATUS = re.compile(r"접수|공고|마감|예정|진행")


class ApplyCenterSource(Source):
    def __init__(self, site: str):
        config = SITES[site]

    def list_request(self, board: Board, page: int) -> Request:

    def detail_url(self, board: Board, pbanc_no: str) -> str:

    def parse_list(self, board: Board, body: str, page_url: str) -> list[ListItem]:
        doc = soup(body)
        if doc.find("tbody") is None:
            raise ParseError(f"{self.name} 목록 표(tbody)를 찾지 못했어요")

                    board=board.key,

                        "공고종류": "정정" if data.get("data-pbanckndcd") == "02" else "일반",
                        "유형": data.get("data-biztynm", ""),
                        "지역": cells[3] if len(cells) > 3 and cells[3] != "-" else "",
                    },
                )
            )

        """목록에 정정 표시(data-pbancKndCd=02)가 있으면 제목과 상관없이 정정공고."""
        if item.meta.get("공고종류") == "정정" and cls.classify(item.title) in (cls.NOTICE, cls.CORRECTION):
            return cls.CORRECTION
        return None

    def parse_detail(self, item: ListItem, body: str) -> Detail:
        doc = soup(body)
        info: dict[str, str] = {}
        districts: list[dict[str, str]] = []
        office: dict[str, str] = {}
        unit_tables: list[list[list[str]]] = []
        for table in doc.find_all("table"):
            caption = text_of(table.find("caption"))
            pairs = key_values(table)
            labels = {text_of(th) for th in table.find_all("th")}
            rows = table.find_all("tr")
            first = rows[0].find_all(["th", "td"], recursive=False) if rows else []
            grid_table = len(rows) > 1 and first and all(c.name == "th" for c in first)
            if "공고상태" in labels or "청약공고 상세" in caption:
                info.update(pairs)
            elif "지구명" in labels:
                if pairs not in districts:
                    districts.append(pairs)
            elif grid_table and ("주택형" in caption or "주택형" in labels):
                unit_tables.append(table_grid(table))  # 모바일용(항목: 값) 표는 첫 행이 머리글이 아니라서 빠짐
            elif "접수처" in caption:
                office.update(pairs)
        if not (info or districts or unit_tables):
            raise ParseError(f"{self.name} 상세의 공고 정보 표를 찾지 못했어요: {item.post_key}")

        rows: list[list[str]] = []  # 지구가 여러 개면 주택형 표를 지구와 순서대로 짝지어 '지구명' 칸을 붙여요
        for number, grid in enumerate(unit_tables):
            name = districts[number].get("지구명", "") if len(unit_tables) == len(districts) > 1 else ""
            if not rows:
                rows.append((["지구명"] if name else []) + grid[0])
            rows += [([name] if name else []) + row for row in grid[1:]]
        units = units_from_tables([(1, "상세 화면", rows)]) if rows else []

        title = info.get("공고명") or text_of(doc.select_one("h3.tit")) or item.title
        lines = [f"{k}: {v}" for k, v in info.items()]
        for district in districts:
            lines.append("[지구] " + ", ".join(f"{k}: {v}" for k, v in district.items()))
        if rows:
            lines += ["[주택형별 임대조건]"] + [" | ".join(r) for r in rows]
        if office:
            lines.append("[접수처] " + ", ".join(f"{k}: {v}" for k, v in office.items()))
        meta = {**info, **{f"접수처 {k}": v for k, v in office.items()}}
        return Detail(title=title, body_text="\n".join(lines), files=self.parse_files(doc), meta=meta, units=units, posted_on=parse_date(info.get("공고일")))

    def parse_files(self, doc) -> list[FileRef]:
        files, seen = [], set()
        for anchor in doc.select("a[href*=selectFileDown]"):
            url = abs_url(self.base, anchor["href"])
            if url in seen:
                continue  # PC용·모바일용 화면에 같은 링크가 두 번
            seen.add(url)
            label = text_of(anchor)
            size = re.search(r"\((\d+)\s*Byte\)", label)
            name = re.sub(r"\s*\(\d+\s*Byte\)\s*$", "", label)
            files.append(FileRef(name, url, len(files), int(size.group(1)) if size else None))
        return files


def key_values(table) -> dict[str, str]:
    """[항목 th][값 td] 짝을 모아요. 한 행에 짝이 여러 개여도 돼요."""
    pairs: dict[str, str] = {}
    for tr in table.find_all("tr"):
        cells = tr.find_all(["th", "td"], recursive=False)
        for left, right in zip(cells, cells[1:]):
            if left.name == "th" and right.name == "td":
                pairs[text_of(left)] = text_of(right)
    return pairs
```

```python
        meta = {}
        for th in doc.select('th[scope="row"]'):
            label = text_of(th)
            if "첨부" not in label:
                meta[label] = text_of(th.find_next_sibling("td"))
        files = [FileRef(text_of(a), abs_url(f"{BASE}/web/board/", a["href"]), i) for i, a in enumerate(doc.select('a[href^="download.do"]'))]
        return Detail(title=text_of(head) or item.title, body_text=body_text(content), files=files, meta=meta, posted_on=parse_date(meta.get("등록일")))
```

```python
                    detail_url=f"{BASE}/ko/page.do?" + urllib.parse.urlencode({**board.params, "board_idx": idx, "cmd": "2"}),
                    referer=page_url,
                    meta={"구분": text_of(tr.select_one("td.bgbar"))},
                )
            )
        return items

    def pre_classify(self, item: ListItem) -> str | None:
        return cls.EXCLUDED if NOT_HOUSING.search(item.meta.get("구분") or "") else None

    def parse_detail(self, item: ListItem, body: str) -> Detail:
        doc = soup(body)
        content = doc.select_one("div#bbs_content")
        if content is None:
            raise ParseError(f"대구 상세 본문(div#bbs_content)을 찾지 못했어요: {item.post_key}")
        view = doc.select_one("div.boardView") or doc
        meta = {text_of(dt): text_of(dt.find_next_sibling("dd")) for dt in view.find_all("dt")}
        files = [FileRef(text_of(a), abs_url(BASE, a["href"]), i) for i, a in enumerate(view.select('a[href^="/dudc/boardDownload/"]'))]
        return Detail(
            title=text_of(view.find("h4")) or item.title, body_text=body_text(content), files=files, meta=meta, posted_on=parse_date(meta.get("등록일"))
        )
```

### 7-6. 울산도시공사 — `sources/local/umca.py`

| 단계 | 주소·방법 |
| --- | --- |
| 목록 (분양) | `https://www.umca.co.kr/umca/bbs/list.do?bbsId=BBS_0000000000000003&mId=001001003000000000&page=N` |
| 목록 (임대) | `https://www.umca.co.kr/umca/bbs/list.do?bbsId=BBS_0000000000000004&mId=001001004000000000&page=N` |
| 상세 | `https://www.umca.co.kr/umca/bbs/view.do?mId=001001004000000000&bbsId=BBS_0000000000000004&dataId=N` (분양은 `BBS_0000000000000003`, `001001003000000000`) |
| 첨부 | 화면의 `HHBbs.DownFile('/umca', bbsId, atchFileId, fileSn)`에서 인자를 읽어 `https://www.umca.co.kr/umca/bbs/FileDown.do?bbsId=…&atchFileId=…&fileSn=K`를 직접 불러요 |
| 주의 | 수집이 깨지면 상세 HTML의 HHBbs.DownFile 인자 순서가 바뀌었는지부터 확인해요 |

```python
"""울산도시공사 — 분양·임대 게시판.

목록  분양 https://www.umca.co.kr/umca/bbs/list.do?bbsId=BBS_0000000000000003&mId=001001003000000000&page=N
      임대 https://www.umca.co.kr/umca/bbs/list.do?bbsId=BBS_0000000000000004&mId=001001004000000000&page=N
      행: 제목 링크 view.do?…&dataId=N, 첨부 아이콘 img alt(파일명), 작성일
상세  https://www.umca.co.kr/umca/bbs/view.do?mId=…&bbsId=…&dataId=N
      table.tbl_bd_view: 항목 th[scope=row]+td(제목·작성일자·유형 …), 본문은 마지막 td[colspan=2]
첨부  화면은 HHBbs.DownFile('/umca', bbsId, atchFileId, fileSn) 스크립트로 받지만, 인자를 읽어 원본 주소를 직접 만들어요:
      https://www.umca.co.kr/umca/bbs/FileDown.do?bbsId=…&atchFileId=…&fileSn=K
"""

import re
import urllib.parse

from mujuthaek_collector.core.files import FileRef
from mujuthaek_collector.core.html import body_text, js_args, parse_date, query_of, soup, text_of
from mujuthaek_collector.errors import ParseError
from mujuthaek_collector.sources.base import Board, Detail, ListItem, Request, Source

BASE = "https://www.umca.co.kr"
SIZE_SUFFIX = re.compile(r"\s*\(\s*[\d.,]+\s*[KMG]?Byte\)\s*$")


class UmcaSource(Source):
    code = "umca"
    name = "울산도시공사"
    provider = "UMCA"
    boards = [
        Board("sale", "분양", {"bbsId": "BBS_0000000000000003", "mId": "001001003000000000"}),
        Board("rent", "임대", {"bbsId": "BBS_0000000000000004", "mId": "001001004000000000"}),
    ]

    def list_request(self, board: Board, page: int) -> Request:
        return Request(f"{BASE}/umca/bbs/list.do?" + urllib.parse.urlencode({**board.params, "page": page}))

    def parse_list(self, board: Board, body: str, page_url: str) -> list[ListItem]:
        doc = soup(body)
        if doc.find("table") is None:
            raise ParseError("울산 목록 표를 찾지 못했어요")
        items = []
        for tr in doc.find_all("tr"):
            anchor = tr.find("a", href=re.compile(r"view\.do\?.*dataId=\d+"))
            if anchor is None:
                continue
            data_id = query_of(anchor["href"])["dataId"]
            found = re.search(r"\d{4}-\d{2}-\d{2}", text_of(tr))
            items.append(
                ListItem(
                    board=board.key,
                    post_key=f"{board.key}-{data_id}",
                    title=text_of(anchor),
                    posted_on=parse_date(found.group(0)) if found else None,
                    detail_url=f"{BASE}/umca/bbs/view.do?"
                    + urllib.parse.urlencode({"mId": board.params["mId"], "bbsId": board.params["bbsId"], "dataId": data_id}),
                    referer=page_url,
                    meta={"첨부": [img["alt"] for img in tr.select("img[alt]") if re.search(r"\.[A-Za-z0-9]{2,5}$", img["alt"])]},
                )
            )
        return items

    def parse_detail(self, item: ListItem, body: str) -> Detail:
        doc = soup(body)
        table = doc.select_one('table[class*="tbl_bd_view"]')
        if table is None:
            raise ParseError(f"울산 상세 표(table.tbl_bd_view)를 찾지 못했어요: {item.post_key}")
        meta = {}
        for th in table.select('th[scope="row"]'):
            label = text_of(th)
            if label not in ("첨부파일", "조회수"):
                meta[label] = text_of(th.find_next_sibling("td"))
        files = []
        for node in table.find_all(["a", "button"]):
            script = (node.get("onclick") or "") + " " + (node.get("href") or "")
            args = js_args(script, "HHBbs.DownFile")
            if not args or len(args) < 4:
                continue
            context, bbs_id, file_id, sn = args[:4]
            name = SIZE_SUFFIX.sub("", text_of(node)).strip()
            url = f"{BASE}{context}/bbs/FileDown.do?" + urllib.parse.urlencode({"bbsId": bbs_id, "atchFileId": file_id, "fileSn": sn})
            files.append(FileRef(name, url, len(files)))
        bodies = table.select('td[colspan="2"]')
        return Detail(
            title=meta.get("제목") or item.title,
            body_text=body_text(bodies[-1]) if bodies else "",
            files=files,
            meta=meta,
            posted_on=parse_date(meta.get("작성일자")),
        )
```

### 7-7. 경상북도개발공사 · 경상남도개발공사 — `sources/local/gbgn.py`

| 단계 | 경북 | 경남 |
| --- | --- | --- |
| 게시판 화면 | `https://www.gbdc.co.kr/boardlist.do?seqId=0000003638` | `https://www.gndc.co.kr/boardlist.do?seqId=0000006202` |
| 목록 (JSON) | `https://www.gbdc.co.kr/getBbsArticleList.do?BBS_ID=4c9b3e75-2935-4bcd-96be-62fb07903949&BBS_TYPE=L&CURRENT_PAGE=N` | `https://www.gndc.co.kr/getBbsArticleList.do?BBS_ID=B491A490314446318099F9D828047900&BBS_TYPE=L&CURRENT_PAGE=N&ATTR01=COLM1_CD%26notice_06%7CCOLM3_CD&ATTR02=COLM3_CD` |
| 상세 | `https://www.gbdc.co.kr/boardview/boardview.do?seqId=0000003638&BBS_ID=4c9b3e75-2935-4bcd-96be-62fb07903949&IPDS_IDX=N&BBS_TYPE=L` | `https://www.gndc.co.kr/boardview/boardview.do?seqId=0000006202&BBS_ID=B491A490314446318099F9D828047900&IPDS_IDX=N&BBS_TYPE=L` |
| 첨부 | `https://www.gbdc.co.kr/common/download.do?fileVirtualPath={파일 경로}&fileOrgName={파일명}` | `https://www.gndc.co.kr/common/download.do?fileVirtualPath={파일 경로}&fileOrgName={파일명}` |

게시판 화면은 자바스크립트로 그리지만 실제 목록은 JSON 주소가 줘서 브라우저가 필요 없어요. 경북은 보상·분양(토지)·임대 공고가 한 게시판이라 분류(`COLM1_VAL`)가 '임대공고'인 글만 열어요. 첨부는 목록 JSON에 있으면 그걸 쓰고, 상세 화면에 있으면 상세 것을 써요.

```python
"""경상북도개발공사 · 경상남도개발공사 — 같은 게시판 시스템이라 설정만 다르게 한 클래스로 받아요.

게시판 화면  경북 https://www.gbdc.co.kr/boardlist.do?seqId=0000003638
             경남 https://www.gndc.co.kr/boardlist.do?seqId=0000006202
목록 (JSON)  경북 https://www.gbdc.co.kr/getBbsArticleList.do?BBS_ID=4c9b3e75-2935-4bcd-96be-62fb07903949&BBS_TYPE=L&CURRENT_PAGE=N
             경남 https://www.gndc.co.kr/getBbsArticleList.do?BBS_ID=B491A490314446318099F9D828047900&BBS_TYPE=L&CURRENT_PAGE=N
                  &ATTR01=COLM1_CD%26notice_06%7CCOLM3_CD&ATTR02=COLM3_CD
             화면은 자바스크립트로 그리지만 목록은 이 주소가 JSON(resultList)으로 줘요. 게시판 화면 주소를 Referer로 보내요.
             항목: IPDS_IDX(글번호), CPDS_SUBJECT(제목), CPDS_WDATE(작성일), COLM1_VAL(분류), COLM2_VAL(상태), COLM3_VAL(지역),
                   COLM4_VAL(유형), sysFileNameStr·orgFileNameStr(첨부 경로·이름, '|'로 구분)
상세         https://www.gbdc.co.kr/boardview/boardview.do?seqId=0000003638&BBS_ID=…&IPDS_IDX=N&BBS_TYPE=L (경남도 같은 모양)
             제목 p.title 또는 div.board-head h3, 항목 div.board-(view-)head의 dt/dd, 본문 div.board-view-body 또는 div.board-body
첨부         https://www.gbdc.co.kr/common/download.do?fileVirtualPath=경로&fileOrgName=이름
             (목록 JSON에 없으면 상세의 pdfViewr('이름','형식','경로','다운로드주소')와 a[href^=/common/download.do]에서)
주의         경북은 보상·분양(토지)·임대 공고가 한 게시판이라 분류가 '임대공고'인 글만 열어요. robots.txt 없음(404) → 표준상 허용.
"""

import json
import re
import urllib.parse

from mujuthaek_collector.core import classify as cls
from mujuthaek_collector.core.files import FileRef
from mujuthaek_collector.core.html import abs_url, body_text, parse_date, query_of, soup, text_of
from mujuthaek_collector.errors import ParseError
from mujuthaek_collector.sources.base import Board, Detail, ListItem, Request, Source

SITES = {
    "gbdc": {
        "name": "경상북도개발공사",
        "provider": "GBDC",
        "base": "https://www.gbdc.co.kr",
        "board": Board("rent", "임대", {"bbs_id": "4c9b3e75-2935-4bcd-96be-62fb07903949", "seq_id": "0000003638", "categories": "임대공고"}),
    },
    "gndc": {
        "name": "경상남도개발공사",
        "provider": "GNDC",
        "base": "https://www.gndc.co.kr",
        "board": Board(
            "rent",
            "임대",
            {"bbs_id": "B491A490314446318099F9D828047900", "seq_id": "0000006202", "ATTR01": "COLM1_CD&notice_06|COLM3_CD", "ATTR02": "COLM3_CD"},
        ),
    },
}
PDF_VIEWER = re.compile(r"pdfViewr\(\s*'([^']*)'\s*,\s*'([^']*)'\s*,\s*'([^']*)'\s*,\s*'([^']*)'")


def val(value) -> str:
    return "" if value in (None, "N", "-") else str(value).strip()


class GbgnSource(Source):
    def __init__(self, site: str):
        config = SITES[site]
        self.code, self.name, self.provider = site, config["name"], config["provider"]
        self.base, self.boards = config["base"], [config["board"]]

    def board_url(self, board: Board) -> str:
        return f"{self.base}/boardlist.do?seqId={board.params['seq_id']}"

    def list_request(self, board: Board, page: int) -> Request:
        attrs = {k: v for k, v in board.params.items() if k.startswith("ATTR")}
        query = {"BBS_ID": board.params["bbs_id"], "BBS_TYPE": "L", "CURRENT_PAGE": page, **attrs}
        return Request(f"{self.base}/getBbsArticleList.do?" + urllib.parse.urlencode(query), referer=self.board_url(board))

    def download_url(self, path: str, name: str) -> str:
        return f"{self.base}/common/download.do?" + urllib.parse.urlencode({"fileVirtualPath": path, "fileOrgName": name})

    def parse_list(self, board: Board, body: str, page_url: str) -> list[ListItem]:
        try:
            rows = json.loads(body).get("resultList")
        except (ValueError, AttributeError) as error:
            raise ParseError(f"{self.name} 목록 응답이 JSON이 아니에요 (구조 변경 확인 필요)") from error
        if rows is None:
            raise ParseError(f"{self.name} 목록 JSON에 resultList가 없어요")
        items = []
        for row in rows:
            seq = str(row["IPDS_IDX"])
            paths = [p for p in (row.get("sysFileNameStr") or "").split("|") if p]
            names = [n for n in (row.get("orgFileNameStr") or "").split("|") if n]
            files = [FileRef(n, self.download_url(p, n), i) for i, (p, n) in enumerate(zip(paths, names))] if len(paths) == len(names) else []
            category = val(row.get("COLM1_VAL"))
            wanted = board.params.get("categories")
            items.append(
                ListItem(
                    board=board.key,
                    post_key=seq,
                    title=re.sub(r"\s+", " ", row.get("CPDS_SUBJECT") or "").strip(),
                    posted_on=parse_date((row.get("CPDS_WDATE") or "")[:10]),
                    detail_url=f"{self.base}/boardview/boardview.do?"
                    + urllib.parse.urlencode({"seqId": board.params["seq_id"], "BBS_ID": board.params["bbs_id"], "IPDS_IDX": seq, "BBS_TYPE": "L"}),
                    referer=self.board_url(board),
                    list_status=val(row.get("COLM2_VAL")) or None,
                    meta={
                        "분류": category,
                        "지역": val(row.get("COLM3_VAL")),
                        "유형": val(row.get("COLM4_VAL")),
                        "범위밖": bool(wanted) and category != wanted,
                    },
                    files=files,
                )
            )
        return items

    def pre_classify(self, item: ListItem) -> str | None:
        return cls.EXCLUDED if item.meta.get("범위밖") else None  # 경북: 임대공고가 아닌 보상·분양(토지) 글

    def parse_detail(self, item: ListItem, body: str) -> Detail:
        doc = soup(body)
        content = doc.select_one('div[class^="board-view-body"]') or doc.select_one("div.board-body")
        if content is None:
            raise ParseError(f"{self.name} 상세 본문(div.board-view-body)을 찾지 못했어요: {item.post_key}")
        title = text_of(doc.select_one("p.title")) or text_of(doc.select_one("div.board-head h3")) or item.title
        head = doc.select_one("div.board-view-head") or doc.select_one("div.board-head")
        meta = {text_of(dt): text_of(dt.find_next_sibling("dd")) for dt in head.find_all("dt")} if head else {}
        files, seen = [], set()
        for name, _ext, path, down in PDF_VIEWER.findall(body):
            if path not in seen:
                seen.add(path)
                files.append(FileRef(name, abs_url(self.base, down), len(files)))
        for anchor in doc.select('a[href^="/common/download.do"]'):
            query = query_of(anchor["href"])
            if query.get("fileVirtualPath") and query["fileVirtualPath"] not in seen:
                seen.add(query["fileVirtualPath"])
                files.append(FileRef(query.get("fileOrgName", text_of(anchor)), abs_url(self.base, anchor["href"]), len(files)))
        return Detail(title=title, body_text=body_text(content), files=files or item.files, meta=meta, posted_on=parse_date(meta.get("작성일")))
```

### 7-8. 출처 목록 — `sources/registry.py`

스케줄러는 `ORDER` 순서대로 한 출처씩 수집해요. 새 기관을 붙일 때는 ① `sources/local/`에 파일 추가 ② 여기 `build_sources`와 `ORDER`에 추가 ③ 마이그레이션으로 `sources` 테이블에 한 줄 추가(sources 테이블의 `code`와 같아야 해요) ④ `save-fixtures`로 화면 저장 후 테스트, 이 순서로 해요.

```python
"""출처 목록. 스케줄러는 ORDER 순서대로 하나씩 수집해요 (동시에 돌리지 않음)."""

from mujuthaek_collector.sources.base import Source
from mujuthaek_collector.sources.local.apply_center import ApplyCenterSource
from mujuthaek_collector.sources.local.dcco import DccoSource
from mujuthaek_collector.sources.local.dudc import DudcSource
from mujuthaek_collector.sources.local.gbgn import GbgnSource
from mujuthaek_collector.sources.local.ih import IhSource
from mujuthaek_collector.sources.local.sh import ShSource
from mujuthaek_collector.sources.local.umca import UmcaSource

ORDER = ["sh", "gh", "bmc", "ih", "dcco", "dudc", "umca", "gbdc", "gndc"]


def build_sources() -> dict[str, Source]:
    sources: list[Source] = [
        ShSource(),
        ApplyCenterSource("gh"),
        ApplyCenterSource("bmc"),
        IhSource(),
        DccoSource(),
        DudcSource(),
        UmcaSource(),
        GbgnSource("gbdc"),
        GbgnSource("gndc"),
    ]
    by_code = {s.code: s for s in sources}
    assert set(by_code) == set(ORDER), "registry.ORDER와 출처 목록이 달라요"
    return by_code


SOURCES = build_sources()


def get(code: str) -> Source:
    if code not in SOURCES:
        raise SystemExit(f"모르는 출처예요: {code} (가능: {', '.join(ORDER)})")
    return SOURCES[code]
```

## 8. 실행 명령과 스케줄러 — `__main__.py`

### 8-1. 명령

모두 `services/collector`에서 `uv run python -m mujuthaek_collector <명령>`으로 실행해요.

| 명령 | 하는 일 | 언제 |
| --- | --- | --- |
| `run` | 스케줄러로 계속 실행 + 상태 확인 서버(`:8091/health`) | Docker 기본 명령, 운영 |
| `run-once <출처>` | 출처 하나를 지금 한 번 수집하고 이벤트까지 발행, 경고를 화면에 출력 | 개발 중 확인, 수동 재수집 |
| `run-once <출처> --recheck` | 마감 전 공고까지 다시 열어 정정 확인 | 정정이 의심될 때 |
| `run-all [--recheck]` | 9곳을 순서대로 한 번 | 배포 직후 확인 |
| `relay` | 아웃박스에 쌓인 이벤트를 한 번 보내기 | RabbitMQ 장애 뒤 |
| `cleanup` | 보관 기한이 지난 원본 파일만 S3에서 지우기 | 매일 4시 자동 |
| `save-fixtures <출처> [--details 3]` | 게시판마다 목록 1페이지와 상세 몇 건을 `tests/fixtures/<출처>/`에 저장 | 수집기를 만들거나 고칠 때 |
| `status` | 최근 수집 회차 20개 (출처, 상태, 새 글 수, 걸린 시간, 경고) | 확인용 |

### 8-2. 스케줄 (서울 시간)

| 작업 | 시간 | 내용 |
| --- | --- | --- |
| 수집 | 평일 9\~18시 매시 5분 | `sources.enabled`가 true인 출처만 `ORDER` 순서대로 하나씩. 앞 수집이 안 끝났으면 이번 차례는 건너뜀 |
| 정정 확인 | 매일 3시 | 마감 전 공고를 다시 열어 바뀌었으면 새 버전 (`--recheck`) |
| 보관 정리 | 매일 4시 | `stored_until`이 지난 원본 파일 삭제 |
| 이벤트 발행 | 5초마다 | 아웃박스 → RabbitMQ. DB·RabbitMQ 연결을 유지하고, 끊기면 다음 차례에 다시 연결 |

모든 작업은 `max_instances=1`(같은 작업이 겹쳐 돌지 않음), `coalesce=True`(밀린 차례는 한 번으로 합침)예요. 한 출처의 실패는 다른 출처를 막지 않아요.

```python
"""수집 워커 실행 명령.

  python -m mujuthaek_collector run                       스케줄러로 계속 실행 (운영·Docker 기본 명령)
  python -m mujuthaek_collector run-once dcco             출처 하나를 지금 한 번 수집
  python -m mujuthaek_collector run-once dcco --recheck   마감 전 공고까지 다시 열어 정정 확인
  python -m mujuthaek_collector run-all                   모든 출처를 순서대로 한 번
  python -m mujuthaek_collector relay                     아웃박스에 쌓인 이벤트를 한 번 보내기
  python -m mujuthaek_collector cleanup                   보관 기한이 지난 원본 파일 지우기
  python -m mujuthaek_collector save-fixtures dcco        테스트용 화면 저장 (tests/fixtures/dcco/)
  python -m mujuthaek_collector status                    최근 수집 회차 보기

스케줄 (서울 시간)
  평일 9~18시 매시 5분   모든 출처 수집 (출처는 하나씩 순서대로)
  매일 3시               정정 확인 (마감 전 공고를 다시 열어 바뀌었으면 새 버전)
  매일 4시               보관 기한이 지난 원본 파일 정리
  5초마다                아웃박스 이벤트 발행
"""

from __future__ import annotations

import argparse
import json
import logging
import threading
from datetime import date, datetime
from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path

from mujuthaek_collector.config import Settings
from mujuthaek_collector.core.file_store import S3FileStore
from mujuthaek_collector.core.http_client import PoliteClient
from mujuthaek_collector.core.storage import PostgresStore
from mujuthaek_collector.pipeline import RunResult, run_source
from mujuthaek_collector.sources.base import Fetcher, Source
from mujuthaek_collector.sources.registry import ORDER, get
from mujuthaek_platform import broker, outbox
from mujuthaek_platform import logging as platform_logging

log = logging.getLogger("mujuthaek_collector")
TIMEZONE = "Asia/Seoul"
HEALTH_PORT = 8091
FIXTURES = Path(__file__).resolve().parents[2] / "tests" / "fixtures"
_last_results: dict[str, dict] = {}  # 상태 확인(/health)에 보여줄 출처별 마지막 결과
_run_lock = threading.Lock()  # 수집 작업은 한 번에 하나만


def make_client(source: Source, settings: Settings) -> Fetcher:
    return PoliteClient(delay_seconds=settings.delay_seconds, legacy_tls=source.legacy_tls, max_file_bytes=settings.max_file_bytes)


def make_file_store(settings: Settings) -> S3FileStore:
    return S3FileStore(settings.s3_bucket, settings.s3_endpoint, settings.s3_access_key, settings.s3_secret_key)


def collect(code: str, settings: Settings, *, recheck: bool = False) -> RunResult:
    source = get(code)
    store = PostgresStore(settings.db_url)
    files = make_file_store(settings)
    client = make_client(source, settings)
    try:
        result = run_source(source, client, store, files, settings, recheck=recheck)
    finally:
        client.close()
        store.close()
    _last_results[code] = {"status": result.status, "new": result.new_count, "at": datetime.now().isoformat(timespec="seconds")}
    return result


def enabled_sources(settings: Settings) -> list[str]:
    """sources.enabled가 true인 출처만 ORDER 순서대로. 문제가 생긴 출처는 DB에서 false로 바꿔 잠시 멈춰요."""
    store = PostgresStore(settings.db_url)
    try:
        enabled = {row[0] for row in store.conn.execute("select code from sources where enabled").fetchall()}
    finally:
        store.close()
    return [code for code in ORDER if code in enabled]


def collect_all(settings: Settings, *, recheck: bool = False) -> None:
    if not _run_lock.acquire(blocking=False):
        log.warning("이전 수집이 아직 끝나지 않아 이번 차례는 건너뛰어요")
        return
    try:
        for code in enabled_sources(settings):
            try:
                collect(code, settings, recheck=recheck)
            except Exception:  # noqa: BLE001 — 한 출처의 실패가 다른 출처를 막지 않게
                log.exception("출처 수집 실패", extra={"source": code})
    finally:
        _run_lock.release()


class Relay:
    """아웃박스 발행기. DB·RabbitMQ 연결을 유지하고, 끊기면 다음 차례에 다시 연결해요."""

    def __init__(self, settings: Settings):
        self.settings = settings
        self.store: PostgresStore | None = None
        self.connection = None
        self.channel = None

    def once(self) -> int:
        try:
            if self.store is None:
                self.store = PostgresStore(self.settings.db_url)
            if self.connection is None or self.connection.is_closed:
                self.connection = broker.connect(self.settings.rabbitmq_url)
                self.channel = self.connection.channel()
            self.connection.process_data_events(0)  # 보낼 게 없을 때도 RabbitMQ 연결 확인(heartbeat)을 처리해요
            return outbox.relay_once(self.store.conn, self.channel)
        except Exception:
            self.close()  # 다음 차례에 새로 연결
            raise

    def quietly(self) -> None:
        try:
            self.once()
        except Exception:  # noqa: BLE001 — RabbitMQ가 잠깐 내려가도 다음 차례에 다시 보내요 (아웃박스에 남아 있음)
            log.exception("이벤트 발행 실패")

    def close(self) -> None:
        for closer in (lambda: self.connection and self.connection.close(), lambda: self.store and self.store.close()):
            try:
                closer()
            except Exception:  # noqa: BLE001
                pass
        self.store = self.connection = self.channel = None


def relay(settings: Settings) -> int:
    """명령줄에서 한 번만 보낼 때."""
    relayer = Relay(settings)
    try:
        return relayer.once()
    finally:
        relayer.close()


def cleanup(settings: Settings, today: date | None = None) -> int:
    """보관 기한(stored_until)이 지난 원본 파일만 S3에서 지워요. 다운로드 주소·해시·추출한 글자·호별 표는 남아요."""
    store = PostgresStore(settings.db_url)
    files = make_file_store(settings)
    removed = 0
    try:
        for file_id, key in store.expired_files(today or date.today()):
            files.delete(key)
            store.mark_file_deleted(file_id)
            removed += 1
    finally:
        store.close()
    log.info("보관 기한 정리", extra={"removed": removed})
    return removed


def save_fixtures(code: str, settings: Settings, details: int) -> None:
    """테스트용 화면 저장: 게시판마다 목록 1페이지와 상세 몇 건을 tests/fixtures/<출처>/에 그대로 저장해요."""
    source = get(code)
    folder = FIXTURES / code
    folder.mkdir(parents=True, exist_ok=True)
    client = make_client(source, settings)
    try:
        for board in source.boards:
            request = source.list_request(board, 1)
            body = client.text(request.url, data=request.data, referer=request.referer)
            ext = "json" if body.lstrip().startswith("{") else "html"
            (folder / f"{board.key}-list.{ext}").write_text(body, encoding="utf-8")
            for item in source.parse_list(board, body, request.url)[:details]:
                detail = source.detail_request(item)
                page = client.text(detail.url, data=detail.data, referer=detail.referer)
                (folder / f"{board.key}-detail-{item.post_key}.html").write_text(page, encoding="utf-8")
                print(f"저장: {folder.name}/{board.key}-detail-{item.post_key}.html  {item.title[:40]}")
    finally:
        client.close()


def print_status(settings: Settings) -> None:
    store = PostgresStore(settings.db_url)
    try:
        rows = store.conn.execute(
            "select source_code, started_at, finished_at, status, new_count, left(coalesce(error, ''), 120) from crawl_runs order by started_at desc limit 20"
        ).fetchall()
    finally:
        store.close()
    for code, started, finished, status, new, error in rows:
        took = f"{(finished - started).seconds}초" if finished else "진행 중"
        print(f"{started:%m-%d %H:%M}  {code:5}  {status:8}  새 {new:3}건  {took:>6}  {error}")


class HealthHandler(BaseHTTPRequestHandler):
    def do_GET(self):  # noqa: N802 — http.server 규칙
        if self.path != "/health":
            self.send_response(404)
            self.end_headers()
            return
        body = json.dumps({"status": "UP", "sources": _last_results}, ensure_ascii=False).encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, *_):  # 상태 확인 요청은 로그에 남기지 않아요
        pass


def serve_health() -> None:
    server = HTTPServer(("0.0.0.0", HEALTH_PORT), HealthHandler)
    threading.Thread(target=server.serve_forever, daemon=True).start()


def run_scheduler(settings: Settings) -> None:
    from apscheduler.schedulers.blocking import BlockingScheduler

    serve_health()
    scheduler = BlockingScheduler(timezone=TIMEZONE)
    common = {"max_instances": 1, "coalesce": True, "misfire_grace_time": 600}
    scheduler.add_job(collect_all, "cron", day_of_week="mon-fri", hour="9-18", minute=5, args=[settings], id="collect", **common)
    scheduler.add_job(collect_all, "cron", hour=3, minute=0, args=[settings], kwargs={"recheck": True}, id="recheck", **common)
    scheduler.add_job(cleanup, "cron", hour=4, minute=0, args=[settings], id="cleanup", **common)
    scheduler.add_job(Relay(settings).quietly, "interval", seconds=5, id="relay", **common)
    log.info("스케줄러 시작", extra={"sources": ORDER})
    scheduler.start()


def main(argv: list[str] | None = None) -> None:
    parser = argparse.ArgumentParser(prog="mujuthaek_collector", description="지방 공사 주거 공고 수집 워커")
    commands = parser.add_subparsers(dest="command", required=True)
    commands.add_parser("run", help="스케줄러로 계속 실행")
    once = commands.add_parser("run-once", help="출처 하나를 지금 한 번 수집")
    once.add_argument("source", choices=ORDER)
    once.add_argument("--recheck", action="store_true", help="마감 전 공고까지 다시 열어 정정 확인")
    every = commands.add_parser("run-all", help="모든 출처를 순서대로 한 번")
    every.add_argument("--recheck", action="store_true")
    commands.add_parser("relay", help="아웃박스 이벤트를 한 번 보내기")
    commands.add_parser("cleanup", help="보관 기한이 지난 원본 파일 지우기")
    fixtures = commands.add_parser("save-fixtures", help="테스트용 화면 저장")
    fixtures.add_argument("source", choices=ORDER)
    fixtures.add_argument("--details", type=int, default=3, help="게시판마다 저장할 상세 수")
    commands.add_parser("status", help="최근 수집 회차 보기")
    args = parser.parse_args(argv)

    platform_logging.setup("collector")
    settings = Settings.from_env()
    if args.command == "run":
        run_scheduler(settings)
    elif args.command == "run-once":
        result = collect(args.source, settings, recheck=args.recheck)
        print(f"{result.source_code}: {result.status}, 새 버전 {result.new_count}건")
        for warning in result.warnings:
            print(f"  - {warning}")
        print(f"이벤트 발행: {relay(settings)}건")
    elif args.command == "run-all":
        collect_all(settings, recheck=args.recheck)
        print(f"이벤트 발행: {relay(settings)}건")
    elif args.command == "relay":
        print(f"이벤트 발행: {relay(settings)}건")
    elif args.command == "cleanup":
        print(f"지운 파일: {cleanup(settings)}개")
    elif args.command == "save-fixtures":
        save_fixtures(args.source, settings, args.details)
    elif args.command == "status":
        print_status(settings)


if __name__ == "__main__":
    main()
```

### 9-1. 가짜 부품 — `tests/fakes.py`, `tests/conftest.py`

`FakeClient`는 "주소 → 응답" 표예요. 등록하지 않은 주소를 요청하면 테스트가 실패해서, 수집기가 어떤 주소를 부르는지 그대로 확인돼요(예: 목록 변화가 없으면 1페이지만 불러야 함). 응답 자리에 오류 객체를 넣으면 그 오류를 던져요.

`tests/__init__.py`는 빈 파일로 둬요 (`from tests.fakes import …`가 되게).

```python
"""테스트용 가짜 부품. 실제 DB·S3·기관 사이트 없이 파이프라인 전체를 돌려볼 수 있어요."""

from __future__ import annotations

from dataclasses import dataclass, field, replace
from datetime import date
from uuid import UUID

from mujuthaek_collector.core.storage import MAX_ATTEMPTS, BoardState, NewVersion, PostRow
from mujuthaek_collector.errors import FileRejected
from mujuthaek_platform.ids import uuid7


@dataclass
class MemoryStore:
    """core.storage.Store 규격을 메모리로 구현해요. 저장된 버전·이벤트를 그대로 꺼내 볼 수 있어요."""

    runs: dict[UUID, dict] = field(default_factory=dict)
    boards: dict[tuple[str, str], BoardState] = field(default_factory=dict)
    posts: dict[UUID, PostRow] = field(default_factory=dict)
    versions: list[NewVersion] = field(default_factory=list)
    deleted_files: list[UUID] = field(default_factory=list)

    @property
    def events(self) -> list[dict]:
        return [v.event for v in self.versions if v.event]

    def by_key(self, post_key: str) -> PostRow:
        return next(p for p in self.posts.values() if p.post_key == post_key)

    def start_run(self, source_code):
        run_id = uuid7()
        self.runs[run_id] = {"source": source_code, "status": "RUNNING"}
        return run_id

    def finish_run(self, run_id, status, new_count, warnings):
        self.runs[run_id].update(status=status, new_count=new_count, warnings=list(warnings))

    def board_state(self, source_code, board_key):
        return replace(self.boards.get((source_code, board_key), BoardState()))

    def save_board_state(self, source_code, board_key, state):
        self.boards[(source_code, board_key)] = replace(state)

    def find_post(self, source_code, post_key):
        return next((p for p in self.posts.values() if p.source_code == source_code and p.post_key == post_key), None)

    def insert_post(self, post):
        if self.find_post(post.source_code, post.post_key) is None:
            self.posts[post.id] = post

    def update_list_fields(self, post_id, list_status, deadline_on):
        post = self.posts[post_id]
        post.list_status = list_status or post.list_status
        post.deadline_on = deadline_on or post.deadline_on

    def queued_posts(self, source_code, board_key, limit):
        queued = [
            p
            for p in self.posts.values()
            if p.source_code == source_code and p.board_key == board_key and (p.status == "PENDING" or (p.status == "FAILED" and p.attempts < MAX_ATTEMPTS))
        ]
        queued.sort(key=lambda p: (p.status != "PENDING", -(p.posted_on or date.min).toordinal()))
        return queued[:limit]

    def notices_posted_on(self, source_code, posted_on):
        return [p for p in self.posts.values() if p.source_code == source_code and p.kind == "NOTICE" and p.posted_on == posted_on]

    def recent_notices(self, source_code, limit=300):
        notices = [p for p in self.posts.values() if p.source_code == source_code and p.kind == "NOTICE"]
        return sorted(notices, key=lambda p: p.posted_on or date.min, reverse=True)[:limit]

    def requeue_open_posts(self, source_code, today, since_days):
        count = 0
        for p in self.posts.values():
            if p.source_code == source_code and p.status == "DONE" and p.kind in ("NOTICE", "CORRECTION") and (p.deadline_on is None or p.deadline_on >= today):
                p.status, count = "PENDING", count + 1
        return count

    def latest_hash(self, post_id):
        mine = [v for v in self.versions if v.post.id == post_id]
        return (mine[-1].version, mine[-1].content_hash) if mine else None

    def mark_done(self, post_id):
        self.posts[post_id].status = "DONE"

    def mark_failed(self, post_id, error):
        post = self.posts[post_id]
        post.status, post.attempts, post.last_error = "FAILED", post.attempts + 1, error

    def save_version(self, new):
        self.versions.append(new)
        post = self.posts[new.post.id]
        post.status, post.latest_version, post.attempts, post.last_error = "DONE", new.version, 0, None

    def expired_files(self, today, limit=500):
        return []

    def mark_file_deleted(self, file_id):
        self.deleted_files.append(file_id)


@dataclass
class MemoryFileStore:
    objects: dict[str, bytes] = field(default_factory=dict)

    def put(self, key, data, content_type):
        self.objects[key] = data
        return key

    def delete(self, key):
        self.objects.pop(key, None)


@dataclass
class FakeClient:
    """주소 → 응답 표. 등록 안 된 주소를 요청하면 테스트가 실패해서, 수집기가 어떤 주소를 부르는지 확인돼요."""

    pages: dict[str, str] = field(default_factory=dict)
    files: dict[str, bytes] = field(default_factory=dict)
    rejected: set[str] = field(default_factory=set)
    requested: list[str] = field(default_factory=list)

    def text(self, url, *, data=None, referer=None):
        self.requested.append(url)
        if url not in self.pages:
            raise AssertionError(f"예상하지 않은 요청: {url}")
        page = self.pages[url]
        if isinstance(page, Exception):
            raise page
        return page

    def download(self, url, *, referer=None):
        self.requested.append(url)
        if url in self.rejected:
            raise FileRejected("robots.txt가 막은 주소")
        return self.files[url]

    def close(self):
        pass
```

### 9-6. 실제 화면 — `tests/test_fixtures.py`

`save-fixtures <출처>`로 저장한 화면이 있는 출처만 돌고, 없으면 건너뛰어요. 저장 파일 이름은 `<게시판 key>-list.html`(경북·경남은 `.json`)과 `<게시판 key>-detail-<글 키>.html`이에요.

| 언제 | 할 일 |
| --- | --- |
| 수집기를 처음 만들 때 | `save-fixtures <출처>` → 테스트 통과까지 파서 고치기 → 저장 화면도 커밋 |
| 기관이 화면을 바꿔 수집이 깨졌을 때 | 다시 `save-fixtures` → 파서 고치기 → 바뀐 화면을 커밋 (그래야 테스트가 지금 사이트와 같아요) |
| 저장 화면에 개인정보가 보이면 | 그 부분을 지우고 커밋 (목록·상세 화면엔 보통 없지만 확인해요) |

```python
"""실제 사이트에서 저장한 화면(tests/fixtures/<출처>/)으로 파서를 확인해요.

저장한 화면이 없는 출처는 건너뛰어요. 기관이 화면을 바꿔 수집기를 고칠 때는 화면도 다시 저장해요.
"""

from pathlib import Path

import pytest

from mujuthaek_collector.sources.base import ListItem
from mujuthaek_collector.sources.registry import SOURCES

FIXTURES = Path(__file__).parent / "fixtures"


def saved(code):
    folder = FIXTURES / code
    return sorted(folder.glob("*-list.*")) if folder.is_dir() else []


@pytest.mark.parametrize("code", sorted(SOURCES))
def test_saved_pages_parse(code):
    lists = saved(code)
    if not lists:
        pytest.skip(f"{code}: 저장한 화면이 없어요 (save-fixtures {code})")
    source = SOURCES[code]
    for path in lists:
        board_key = path.name.split("-list.")[0]
        board = next(b for b in source.boards if b.key == board_key)
        items = source.parse_list(board, path.read_text(encoding="utf-8"), source.list_request(board, 1).url)
        assert items, f"{path.name}: 목록이 비어 있어요"
        assert all(i.post_key and i.title for i in items), f"{path.name}: 글 키나 제목이 빈 글이 있어요"
        for detail_path in sorted(path.parent.glob(f"{board_key}-detail-*.html")):
            post_key = detail_path.stem.split("-detail-", 1)[1]
            item = next((i for i in items if i.post_key == post_key), None) or ListItem(board_key, post_key, "", None, None)
            detail = source.parse_detail(item, detail_path.read_text(encoding="utf-8"))
```

### `infra/docker-compose.yml`의 collector 서비스

팀 로컬 설정에 collector 서비스가 이미 있어요. 평소엔 `make infra`로 DB·RabbitMQ·MinIO만 띄우고 수집기는 `uv run`으로 직접 실행하고, 전체를 Docker로 띄울 때는 `make up`(`apps` 프로필)을 써요. 컨테이너 안에서는 주소가 `localhost`가 아니라 서비스 이름(`postgres`, `rabbitmq`, `minio`)이라서 환경 변수로 넘겨요.

```yaml
  collector:
    build: { context: .., dockerfile: services/collector/Dockerfile }
    profiles: [apps]
    depends_on:
      migrate-collector: { condition: service_completed_successfully }
      rabbitmq: { condition: service_healthy }
    environment: &worker-env
      SERVICE_NAME: collector
      DB_URL: postgresql://collector_app:${COLLECTOR_DB_PASSWORD}@postgres:5432/collector
      RABBITMQ_URL: amqp://${RABBITMQ_USER}:${RABBITMQ_PASSWORD}@rabbitmq:5672/
      S3_ENDPOINT: http://minio:9000
      S3_BUCKET: ${S3_BUCKET}
      AWS_ACCESS_KEY_ID: ${MINIO_ROOT_USER}
      AWS_SECRET_ACCESS_KEY: ${MINIO_ROOT_PASSWORD}
    ports: ["8091:8091"]
```

### AWS 연결 때 (다음 주 예정) — `infra/docker-compose.prod.yml`의 collector 서비스

지금 로컬 개발에는 필요 없어요. AWS로 옮길 때 같은 서비스에 재시작, 메모리 상한, S3(EC2 역할 인증), 로그 전송을 더해요. 코드는 그대로이고 환경 값만 바뀌어요: `DB_URL`은 RDS의 collector 데이터베이스(Parameter Store에서 주입), `S3_ENDPOINT`는 빈 값, S3 키는 넣지 않아요. RDS에는 `infra/db/init/01-databases.sql`을 한 번 실행하고 같은 마이그레이션을 적용해요.

```yaml
  collector:
    restart: unless-stopped
    environment:
      S3_ENDPOINT: ""          # 비우면 AWS S3. 인증은 EC2 역할로 (키를 넣지 않음)
      AWS_ACCESS_KEY_ID: ""
      AWS_SECRET_ACCESS_KEY: ""
    deploy:
      resources:
        limits: { cpus: "1", memory: 1g }
    logging:
      driver: awslogs
      options: { awslogs-group: /mujuthaek/collector, awslogs-region: ap-northeast-2 }
```
